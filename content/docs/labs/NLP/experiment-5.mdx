### Code

```python
import nltk
from nltk.tokenize import word_tokenize
from nltk import pos_tag

text = input("Enter your text: ")

tokenized = word_tokenize(text)

tagged = pos_tag(tokenized)

print(tokenized)
print(tagged)
```
