# Bloom Filter and Hashing (OCR Topic)

Bloom Filter is a probabilistic structure used to check whether an element is possibly present or definitely not present.

## Given setup in notes

$$
m=5,\quad h_1(x)=x\bmod 5,\quad h_2(x)=(2x+3)\bmod 5
$$

Bit array example shown:

$$
[1,1,0,0,1]
$$

## Query example: 16

$$
h_1(16)=1,\quad h_2(16)=0
$$

Both bit positions were 1, so Bloom filter returns positive.

But in note this element was actually not inserted, so this is a **false positive**.

Hence statement: 16 was probably present.

## Hash Function definition (OCR normalized)

A hash function is any function that maps data of arbitrary size to fixed-size values.
The returned values are called hashes.
