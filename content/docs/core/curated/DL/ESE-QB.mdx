### Q1. Explain the basic operation of a single neuron, including the role of weights, bias, and activation functions. <QuestionDot color="cyan" text="MSE-QB" />
</LongQuestion>

A single neuron is the basic processing unit of a neural network. Its operation has three steps:

**Step 1 — Weighted Sum:**

Each input $x_i$ is multiplied by a corresponding weight $w_i$, and a bias $b$ is added:

$$z = \sum_{i=1}^{n} w_i x_i + b = w_1x_1 + w_2x_2 + \dots + w_nx_n + b$$

**Step 2 — Activation Function:**

The weighted sum $z$ is passed through an activation function $f(z)$ to produce the output $y$:

$$y = f(z)$$

**Roles of each component:**

| Component | Role |
|-----------|------|
| <Highlight color="green">**Weights ($w_i$)**</Highlight> | Control the importance/strength of each input. Learned during training. |
| <Highlight color="orange">**Bias ($b$)**</Highlight> | Shifts the activation threshold, allowing the neuron to fire even when all inputs are zero. |
| <Highlight color="blue">**Activation Function**</Highlight> | Introduces non-linearity so the network can learn complex patterns. Without it, the network reduces to a linear model. |

Common activation functions: Sigmoid, Tanh, ReLU.

### Q2. Briefly describe the perceptron learning rule and its goal. <QuestionDot color="yellow" text="IA1-QB" />
</LongQuestion>

The <Highlight color="blue">**Perceptron Learning Rule**</Highlight> is a supervised learning algorithm that adjusts weights based on prediction error.

**Weight Update Formula:**

$$w_i^{(\text{new})} = w_i^{(\text{old})} + \alpha\,(t - y)\,x_i$$

where $\alpha$ is the learning rate, $t$ is the target output, and $y$ is the actual output.

**Goal:** Find a set of weights such that the perceptron correctly classifies all linearly separable training samples. The rule guarantees convergence in finite steps for linearly separable problems *(Perceptron Convergence Theorem)*.

- If $y = t$ → no update (prediction is correct).
- If $y \neq t$ → weights are adjusted in the direction that reduces error.

### Q4. Provide a simple diagram of a feedforward neural network with one hidden layer.
</LongQuestion>

A feedforward neural network with one hidden layer has three layers:

```
Input Layer     Hidden Layer     Output Layer
  (x1)  ──┐
           ├──→  (h1)  ──┐
  (x2)  ──┤              ├──→  (y)
           ├──→  (h2)  ──┘
  (x3)  ──┘
```

- **Input layer:** receives raw features.
- **Hidden layer:** applies weighted sums + activation function (e.g., ReLU or Sigmoid).
- **Output layer:** produces final prediction (Sigmoid for binary, Softmax for multi-class).

$$z^{[1]} = W^{[1]}X + b^{[1]}, \quad a^{[1]} = f(z^{[1]})$$
$$z^{[2]} = W^{[2]}a^{[1]} + b^{[2]}, \quad \hat{y} = f(z^{[2]})$$

<LongQuestion>
### Q5. Explain the delta learning rule and its application in training neural networks.
</LongQuestion>

The <Highlight color="blue">**Delta Rule**</Highlight> (Widrow-Hoff rule) is a gradient descent-based learning rule for single-layer networks with continuous activation functions.

**Update Rule:**

$$\Delta w_i = \alpha\,(t - \hat{y})\,f'(z)\,x_i$$

where:
- $\alpha$ = learning rate
- $t - \hat{y}$ = error (target − predicted)
- $f'(z)$ = derivative of the activation function
- $x_i$ = input value

**Key differences from Perceptron Rule:**

| Perceptron Rule | Delta Rule |
|---|---|
| Binary outputs only | Works with continuous outputs |
| No derivative of activation | Uses $f'(z)$ (gradient-based) |
| Converges for linearly separable only | Foundation of backpropagation |

**Application:** The Delta Rule is the basis of backpropagation. It is applied layer by layer (via chain rule) to update all weights in multi-layer networks.

### Q7 & Q8. List and explain two common activation functions and provide their mathematical formula. <QuestionDot color="yellow" text="IA1-QB" />
</LongQuestion>

**1. <Highlight color="blue">Sigmoid Function</Highlight>**

$$f(x) = \frac{1}{1 + e^{-x}}$$

- Output range: $(0, 1)$
- Converts any value to a probability.
- Used in binary classification output layers.
- Drawback: suffers from <Highlight color="red">**vanishing gradients**</Highlight> for very large or very small inputs.

**2. <Highlight color="blue">ReLU (Rectified Linear Unit)</Highlight>**

$$f(x) = \max(0,\, x)$$

- Output range: $[0, \infty)$
- Most widely used in hidden layers.
- Computationally efficient and avoids vanishing gradients (for positive inputs).
- Drawback: <Highlight color="red">**dying ReLU**</Highlight> problem — neurons can get stuck at zero.

**Bonus — Tanh:**

$$f(x) = \tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$$

Output range: $(-1, 1)$. Used in hidden layers of RNNs.

<LongQuestion>
### Q11. Explain the role of backpropagation in deep neural networks. <QuestionDot color="cyan" text="MSE-QB" />
</LongQuestion>

<Highlight color="blue">**Backpropagation**</Highlight> is the algorithm used to compute gradients of the loss function with respect to each weight in the network, enabling weight updates via gradient descent.

**Role (step by step):**

1. **Forward pass:** Compute predictions $\hat{y}$ and calculate the loss $\mathcal{L}$.
2. **Compute output gradient:** $\frac{\partial \mathcal{L}}{\partial \hat{y}}$
3. **Propagate backward using chain rule:** For each layer $l$:

$$\frac{\partial \mathcal{L}}{\partial W^{[l]}} = \frac{\partial \mathcal{L}}{\partial A^{[l]}} \cdot \frac{\partial A^{[l]}}{\partial Z^{[l]}} \cdot \frac{\partial Z^{[l]}}{\partial W^{[l]}}$$

4. **Update weights:**

$$W^{[l]} \leftarrow W^{[l]} - \eta\,\frac{\partial \mathcal{L}}{\partial W^{[l]}}$$

**Key importance:** Without backpropagation, it would be computationally impossible to train deep networks with millions of parameters efficiently. It makes learning feasible by computing all gradients in a single backward pass.

<LongQuestion>
### Q13. Discuss the fundamental working principles of deep neural networks.
</LongQuestion>

A <Highlight color="blue">**Deep Neural Network (DNN)**</Highlight> works by learning a hierarchy of representations through multiple stacked layers.

**Working Principle:**

1. <Highlight color="green">**Layered Representation:**</Highlight> Each layer transforms the input into a more abstract representation. Early layers detect low-level features (edges), deeper layers detect high-level features (objects).

2. <Highlight color="green">**Forward Propagation:**</Highlight> Input is passed layer-by-layer:
$$Z^{[l]} = W^{[l]} A^{[l-1]} + b^{[l]}, \quad A^{[l]} = f(Z^{[l]})$$

3. <Highlight color="orange">**Loss Computation:**</Highlight> The output is compared to the target using a loss function (e.g., MSE, cross-entropy).

4. <Highlight color="orange">**Backpropagation:**</Highlight> Gradients of the loss are computed backwards using the chain rule.

5. <Highlight color="blue">**Weight Update (Gradient Descent):**</Highlight>
$$W \leftarrow W - \eta\,\frac{\partial \mathcal{L}}{\partial W}$$

6. **Repeat** for many epochs until the loss converges.

```
Input → [Layer 1: Edges] → [Layer 2: Shapes] → [Layer 3: Objects] → Output
```

<LongQuestion>
### Q17. How does a shallow Neural Network perform binary classification? <QuestionDot color="cyan" text="MSE-QB" />
</LongQuestion>

A <Highlight color="blue">**shallow neural network**</Highlight> (one hidden layer + one output layer) performs <Highlight color="green">**binary classification**</Highlight> by transforming input features into a probability value using <Highlight color="cyan">**weighted layers**</Highlight> and <Highlight color="cyan">**activation functions**</Highlight>.

#### Forward Propagation

$$A^{[0]} = X$$

$$Z^{[1]} = W^{[1]} A^{[0]} + b^{[1]}, \qquad A^{[1]} = f^{[1]}(Z^{[1]}) \quad \text{(ReLU / tanh)}$$

$$Z^{[2]} = W^{[2]} A^{[1]} + b^{[2]}, \qquad A^{[2]} = \sigma(Z^{[2]}) \quad \text{(Sigmoid)}$$

#### Decision Rule

$$\hat{y} = \begin{cases} 1 & A^{[2]} \geq 0.5 \\ 0 & A^{[2]} < 0.5 \end{cases}$$

#### Training

**Loss (Binary Cross-Entropy):**
$$\mathcal{L} = -\left[t \log A^{[2]} + (1-t)\log(1 - A^{[2]})\right]$$

**Weight Update:**
$$W^{[l]} \leftarrow W^{[l]} - \alpha \frac{\partial \mathcal{L}}{\partial W^{[l]}}, \qquad b^{[l]} \leftarrow b^{[l]} - \alpha \frac{\partial \mathcal{L}}{\partial b^{[l]}}$$

Repeat for multiple epochs until convergence.

<LongQuestion>
### Q2. Describe regularization techniques in Deep learning (early stopping, dataset augmentation, parameter sharing, injecting noise into input, ensemble methods, dropout,) <QuestionDot color="yellow" text="IA1-QB" /> <QuestionDot color="green" text="Asked in IA1" /> <QuestionDot color="blue" text="Asked in MSE" />
</LongQuestion>

Deep learning models often suffer from <Highlight color="red">**overfitting**</Highlight> and <Highlight color="red">**slow convergence**</Highlight>. <Highlight color="blue">**Regularization techniques**</Highlight> help reduce overfitting by controlling model complexity, while <Highlight color="blue">**optimization techniques**</Highlight> help minimize the loss function efficiently during training.

Let the prediction of a model be:

$$
\hat{y} = w_1 x_1 + w_2 x_2 + \dots + w_m x_m + b
$$

where $w_j$ are weights and $b$ is bias.

Let the original loss function (Mean Squared Error) be:

$$
L = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
$$

---

#### Regularization Techniques

**L1 Regularization (Lasso):**

$$
L_{total} = L + \lambda \sum_{j=1}^{m} |w_j|
$$

It adds a penalty equal to the absolute values of weights.
It <Highlight color="green">**forces some weights to become zero**</Highlight>, performs feature selection, and reduces overfitting.

**L2 Regularization (Ridge):**

$$
L_{total} = L + \lambda \sum_{j=1}^{m} w_j^2
$$

It adds a penalty equal to squared weights.
It <Highlight color="green">**reduces large weight values**</Highlight> and prevents the model from becoming too sensitive to training data.

**Early Stopping:**

Training is stopped when <Highlight color="orange">**validation loss starts increasing**</Highlight> while training loss continues decreasing.
This prevents the model from learning noise in the training data.

**Dropout:**

<Highlight color="orange">**Randomly deactivates neurons**</Highlight> during training, reducing co-adaptation and forcing the model to learn redundant representations.

**Dataset Augmentation:**

Artificially increases the size and diversity of the training set by applying transformations like <Highlight color="orange">**rotation, flipping, and scaling**</Highlight>. It prevents the model from memorizing specific training samples.

**Parameter Sharing:**

The same set of weights is reused across different parts of a model (e.g., in <Highlight color="green">**CNN filters**</Highlight>). This significantly reduces the number of trainable parameters and controls model complexity.

**Injecting Noise into Input:**

Adding small random perturbations (<Highlight color="orange">**Gaussian noise**</Highlight>) to input data during training. It forces the model to learn stable patterns and improves robustness.

**Ensemble Methods:**

Combining predictions from <Highlight color="green">**multiple independently trained models**</Highlight> (via averaging or voting). It reduces variance as errors from individual models tend to cancel out.

---

#### Optimization Techniques

**Gradient Descent:**

$$
w = w - \eta \frac{\partial L}{\partial w}
$$

where $\eta$ is the <Highlight color="orange">**learning rate**</Highlight>.
It updates weights in the direction of minimum loss.

**Stochastic Gradient Descent (SGD):**

Updates weights using <Highlight color="green">**one training sample at a time**</Highlight> for faster convergence.

**Adam Optimizer:**

An <Highlight color="green">**adaptive optimization algorithm**</Highlight> that adjusts learning rates for each parameter and improves convergence speed.

---

#### Conclusion

Regularization techniques such as L1, L2, Early Stopping, Dropout, Dataset Augmentation, Parameter Sharing, Noise Injection, and Ensemble Methods control overfitting by limiting model complexity and improving robustness. Optimization techniques such as Gradient Descent, SGD, and Adam efficiently minimize the loss function. Together, they ensure stable and effective training of deep learning models.

<LongQuestion>
### Q3. Differentiate between L1 and L2 regularization techniques. <QuestionDot color="cyan" text="MSE-QB" />
</LongQuestion>

Both L1 and L2 regularization add a penalty term to the loss function to prevent large weights and reduce overfitting.

#### <Highlight color="blue">**L1 Regularization (Lasso)**</Highlight>

$$\mathcal{L}_{L1} = L(w) + \frac{\lambda}{2m} \sum \|w\|$$

- Adds the **absolute value** of weights to the loss function.
- Produces <Highlight color="green">**sparse solutions**</Highlight> (weights -> 0); performs <Highlight color="green">**implicit feature selection**</Highlight>.
- Robust to outliers.
- Useful when many features are irrelevant (high-dimensional data).

#### <Highlight color="blue">**L2 Regularization (Ridge / Weight Decay)**</Highlight>

$$\mathcal{L}_{L2} = L(w) + \lambda \sum w^2$$

Also written as:

$$\widetilde{\mathcal{L}}(w) = \mathcal{L}(w) + \frac{\alpha}{2}\|w\|^2$$

- Adds the **squared value** of weights; shrinks all weights but **never to exactly zero**.
- Generally preferred in deep learning as **weight decay**.
- Not robust to outliers due to the squared term.

#### Updated Gradient (L2)

$$\nabla\widetilde{\mathcal{L}}(w) = \nabla\mathcal{L}(w) + \alpha w \qquad \Rightarrow \qquad w_{t+1} = w_t - \eta\,\nabla\mathcal{L}(w_t) - \eta\alpha\, w_t$$

#### Geometric Interpretation

- **L2** constraint region: circle ($w_1^2 + w_2^2 \leq C$) - weights are small but non-zero.
- **L1** constraint region: diamond ($|w_1| + |w_2| \leq C$) - optimal solution hits a corner, driving some weights to exactly zero.

#### Numerical Example

**Given:** Original Loss $= 10$, $W = [2,\ -3,\ 1]$, $\lambda = 0.1$

**L1:**

$$\sum|w| = 2 + 3 + 1 = 6 \qquad \Rightarrow \qquad \mathcal{L}_{L1} = 10 + 0.1 \times 6 = \boxed{10.6}$$

**L2:**

$$\sum w^2 = 4 + 9 + 1 = 14 \qquad \Rightarrow \qquad \mathcal{L}_{L2} = 10 + 0.1 \times 14 = \boxed{11.4}$$

| Property | L1 Regularization | L2 Regularization |
|----------|------------------|------------------|
| **Penalty term** | $\lambda\sum\Vert w\Vert$ | $\lambda\sum w^2$ |
| **Also known as** | Lasso | Ridge / Weight Decay |
| **Solution type** | <Highlight color="green">**Sparse**</Highlight> (weights -> 0) | Non-sparse (weights shrink) |
| **Feature selection** | Yes (implicit) | No |
| **Robustness** | Robust to outliers | Not robust |
| **Constraint region** | Diamond-shaped | Circular |

<LongQuestion>
### Q4. Discuss different types of biases in machine learning models. / Explain bias-variance trade off. <QuestionDot color="cyan" text="MSE-QB" /> <QuestionDot color="blue" text="Asked in MSE" />
</LongQuestion>

In Machine Learning, **bias** can refer to errors arising from incorrect assumptions or flawed data collection.

#### Types of Biases (Mnemonic: **SCEMA**)

1. <Highlight color="orange">**S - Selection Bias:**</Highlight> Training data is not representative of the real population (e.g., training only on urban images for a global model).
2. <Highlight color="orange">**C - Confirmation Bias:**</Highlight> Interpreting results to confirm pre-existing assumptions while ignoring contradictory evidence.
3. <Highlight color="orange">**E - Exclusion Bias:**</Highlight> Certain groups or data points are unintentionally excluded from the dataset.
4. <Highlight color="orange">**M - Measurement Bias:**</Highlight> Systematic errors in how data was recorded, labeled, or classified.
5. <Highlight color="orange">**A - Algorithm Bias:**</Highlight> The model's inductive assumptions (e.g., linearity) cause systematic errors regardless of data size.

#### Impact on Learning (Mnemonic: **PUSS**)

- <Highlight color="red">**P - Poor Generalization:**</Highlight> Model performs well on training data but fails on real-world, diverse inputs.
- <Highlight color="red">**U - Unfairness:**</Highlight> Discriminatory outcomes for underrepresented groups.
- <Highlight color="red">**S - Skewed Accuracy:**</Highlight> High training accuracy but total failure in production.
- <Highlight color="red">**S - Systematic Error:**</Highlight> Unlike variance, bias errors are consistent and not reducible by more training data alone.

The <Highlight color="blue">**Bias-Variance Tradeoff**</Highlight> formalizes this:

$$E\left[(y - \hat{f}(x))^2\right] = \text{Bias}^2 + \text{Variance} + \sigma^2$$

- **High Bias:** Overly simple model -> <Highlight color="red">**Underfitting**</Highlight>.
- **High Variance:** Overly complex model -> <Highlight color="red">**Overfitting**</Highlight>.

<LongQuestion>
### Q5. Describe regularization techniques in Deep learning (early stopping, dataset augmentation, parameter sharing, injecting noise into input, ensemble methods, dropout,) <QuestionDot color="cyan" text="MSE-QB" />
</LongQuestion>

<Highlight color="blue">**Regularization**</Highlight> is a set of techniques to prevent a model from <Highlight color="red">**overfitting**</Highlight> - i.e., learning the training data's noise rather than the underlying pattern.

#### Why It's Important

- Deep networks have millions of parameters and can perfectly fit training data, including noise.
- Without regularization, the model generalizes poorly to new data.
- Regularization keeps weight values controlled, forcing the model to learn simpler, more generalizable patterns.

#### Two Common Methods

**1. <Highlight color="blue">L2 Regularization (Weight Decay)</Highlight>**

$$\widetilde{\mathcal{L}} = \mathcal{L}(w) + \frac{\lambda}{2}\|w\|^2$$

Penalizes large weights by adding the squared sum of weights to the loss. Keeps all features but shrinks their influence.

**2. <Highlight color="blue">Dropout</Highlight>**

During each training iteration, randomly sets a fraction $p$ of neuron outputs to zero:
$$h' = h \odot m, \quad m_i \sim \text{Bernoulli}(1-p)$$

This prevents neurons from co-adapting and forces the network to learn redundant representations.

<LongQuestion>
### Q6. Explain the working of backpropagation in deep neural networks. Derive the weight update rule using gradient descent. / Describe Forward and Backward Propagation in ANN <QuestionDot color="cyan" text="MSE-QB" />
</LongQuestion>

Training an ANN involves two main processes: <Highlight color="blue">**Forward Propagation**</Highlight> and <Highlight color="blue">**Backward Propagation**</Highlight>.

#### Forward Propagation

Input $A^{[0]} = X$ is passed through the network layer by layer:

$$Z^{[l]} = W^{[l]} A^{[l-1]} + b^{[l]}, \qquad A^{[l]} = f\!\left(Z^{[l]}\right)$$

Final layer produces prediction $\hat{y} = A^{[L]}$, and loss is computed:

$$\mathcal{L} = \frac{1}{2}(y - \hat{y})^2$$

#### Backward Propagation

Error is propagated backward using the <Highlight color="orange">**chain rule**</Highlight>:

$$\frac{\partial \mathcal{L}}{\partial W} = \frac{\partial \mathcal{L}}{\partial A} \cdot \frac{\partial A}{\partial Z} \cdot \frac{\partial Z}{\partial W}$$

#### Derivation of Weight Update Rule (Gradient Descent)

The goal is to move weights in the direction that **minimizes** the loss:

$$\Delta W = -\alpha \frac{\partial \mathcal{L}}{\partial W}$$

$$W^{[l]} \leftarrow W^{[l]} - \eta \,\frac{\partial \mathcal{L}}{\partial W^{[l]}}, \qquad b^{[l]} \leftarrow b^{[l]} - \eta \,\frac{\partial \mathcal{L}}{\partial b^{[l]}}$$

where $\eta$ is the <Highlight color="orange">**learning rate**</Highlight>.

### Q1 / Q7. What is the primary purpose of a convolutional layer in a CNN? / Explain the role of the convolutional layer in feature extraction.
</LongQuestion>

The **convolutional layer** is the core building block of a CNN. Its primary purpose is **automatic feature extraction** from input data.

**How it works:**

A learnable filter (kernel) of size $F \times F$ slides across the input with a given stride, computing a dot product at each position:

$$z_{i,j} = \sum_{m=0}^{F-1}\sum_{n=0}^{F-1} x_{i+m,\, j+n} \cdot w_{m,n} + b$$

The result is a **feature map** (activation map) that highlights where a specific pattern is present.

**Role in feature extraction:**

- <Highlight color="green">**Early layers:**</Highlight> Detect low-level features — edges, corners, gradients.
- <Highlight color="orange">**Middle layers:**</Highlight> Detect mid-level features — textures, shapes, curves.
- <Highlight color="blue">**Deep layers:**</Highlight> Detect high-level, semantic features — eyes, wheels, faces.

**Key advantages:**
- <Highlight color="green">**Parameter sharing:**</Highlight> Same filter weights applied everywhere → fewer parameters.
- <Highlight color="green">**Local connectivity:**</Highlight> Each neuron connects to a small local region, capturing spatial structure.
- <Highlight color="green">**Translation invariance:**</Highlight> Features detected regardless of position in image.

<LongQuestion>
### Q2 / Q9. Define "loss function" and "backpropagation" in the context of deep learning. / What is the role of backpropagation in CNN training?
</LongQuestion>

**Loss Function:**

A <Highlight color="blue">**loss function**</Highlight> $\mathcal{L}$ measures the error between the network's predicted output $\hat{y}$ and the true label $y$.

| Task | Loss Function | Formula |
|------|--------------|---------|
| Regression | Mean Squared Error (MSE) | $\mathcal{L} = \frac{1}{n}\sum(y_i - \hat{y}_i)^2$ |
| Binary Classification | Binary Cross-Entropy | $\mathcal{L} = -[y\log\hat{y} + (1-y)\log(1-\hat{y})]$ |
| Multi-class | Categorical Cross-Entropy | $\mathcal{L} = -\sum_c y_c \log\hat{y}_c$ |

**Backpropagation:**

<Highlight color="blue">**Backpropagation**</Highlight> is the algorithm that computes gradients of the loss w.r.t. every weight in the network using the **chain rule**, so weights can be updated via gradient descent.

**Steps:**

1. **Forward pass:** Compute $\hat{y}$ and $\mathcal{L}$.
2. **Backward pass:** Propagate error from output to input layer using:

$$\frac{\partial \mathcal{L}}{\partial W^{[l]}} = \frac{\partial \mathcal{L}}{\partial A^{[l]}} \cdot \frac{\partial A^{[l]}}{\partial Z^{[l]}} \cdot \frac{\partial Z^{[l]}}{\partial W^{[l]}}$$

3. **Weight update (Gradient Descent):**

$$W^{[l]} \leftarrow W^{[l]} - \eta\,\frac{\partial \mathcal{L}}{\partial W^{[l]}}$$

**Role in CNN:** Backprop adjusts filter weights (kernels), FC layer weights, and biases — training the CNN to detect increasingly useful features.

### Q6 / Q8 / Q11 / Q12. Describe the basic layers of a CNN. / What is a CNN and why is it effective for image processing? / Explain the detailed structure of a CNN. / Explain the purpose of pooling layers.
</LongQuestion>

A <Highlight color="blue">**Convolutional Neural Network (CNN)**</Highlight> is a deep learning architecture specifically designed for processing grid-structured data (images, video). It is effective for images because it exploits **local spatial structure**, **parameter sharing**, and **hierarchical feature learning**.

#### Layers of a CNN

**1. <Highlight color="green">Convolutional Layer</Highlight>**

Applies $K$ learnable filters of size $F \times F$ to extract feature maps.

$$z = \text{input} * \text{filter} + b$$

Output size: $\left\lfloor\frac{N - F + 2P}{S}\right\rfloor + 1$ where $N$ = input size, $P$ = padding, $S$ = stride.

Followed by an activation function (typically ReLU): $a = \max(0, z)$

**2. <Highlight color="orange">Pooling Layer</Highlight>**

Reduces spatial dimensions (downsampling) while retaining dominant features.

- **Max Pooling:** Takes the maximum value in each window → preserves strongest activations.
- **Average Pooling:** Takes the mean of each window.

$$\text{Max Pool}_{2\times2}:\quad \begin{bmatrix}1&3\\2&4\end{bmatrix} \rightarrow 4$$

**Purpose of pooling:**
- Reduces computation and memory usage.
- Provides local translation invariance.
- Prevents overfitting by reducing the number of parameters.

**3. <Highlight color="blue">Fully Connected (FC) Layer</Highlight>**

Flattens the feature maps into a 1D vector and performs classification using standard weighted connections.

$$\hat{y} = \text{softmax}(W \cdot \text{flatten}(A) + b)$$

#### Typical CNN Pipeline

```
Input Image
  → [Conv + ReLU] × n   (feature extraction)
  → [Pooling]            (downsampling)
  → [Conv + ReLU] × n
  → [Pooling]
  → Flatten
  → [FC Layer + ReLU]
  → [FC + Softmax]       (output probabilities)
```

<LongQuestion>
### Q1 / Q2. What is an RNN and why is it suitable for sequential data? / What is the main difference between an RNN and a feedforward network?
</LongQuestion>

A <Highlight color="blue">**Recurrent Neural Network (RNN)**</Highlight> is a neural network with **cyclic connections** that allow information to persist across time steps, making it suitable for sequential data.

**Why suitable for sequential data:**
- Maintains a <Highlight color="green">**hidden state**</Highlight> $h_t$ that acts as memory, capturing context from all previous inputs.
- Processes inputs one step at a time while updating its state: output at step $t$ depends on both current input $x_t$ and past hidden state $h_{t-1}$.

**Key difference from FNN:**

| Property | Feedforward NN | RNN |
|----------|---------------|-----|
| **Connections** | Acyclic (no loops) | Cyclic (recurrent loops) |
| **Memory** | None | Hidden state $h_t$ |
| **Input** | Fixed-size | Variable-length sequences |
| **Weight sharing** | Different per layer | Shared across all time steps |

---

<LongQuestion>
### Q3 / Q4 / Q7 / Q8. Describe the architecture of a simple RNN, including hidden states, recurrent connections, and how it processes sequential data.
</LongQuestion>

#### Architecture

An RNN at each time step $t$ takes:
- $x_t$ — current input
- $h_{t-1}$ — previous hidden state

And computes:

$$h_t = \tanh(W_{xh}\,x_t + W_{hh}\,h_{t-1} + b_h)$$

$$y_t = W_{hy}\,h_t + b_y$$

where:
- $W_{xh}$ — input-to-hidden weight matrix
- $W_{hh}$ — hidden-to-hidden (recurrent) weight matrix
- $W_{hy}$ — hidden-to-output weight matrix

#### Role of Recurrent Connections

The recurrent connection via $W_{hh}$ feeds the previous hidden state back into the current computation — this is what gives the RNN its **memory**. The same $W_{hh}$, $W_{xh}$, $W_{hy}$ are **shared across all time steps** (parameter sharing).

#### Sequential Processing

```
x₁ → [RNN cell] → h₁ → y₁
              ↓
x₂ → [RNN cell] → h₂ → y₂
              ↓
x₃ → [RNN cell] → h₃ → y₃
```

At each step, the hidden state $h_t$ summarizes all past information $x_1, x_2, \ldots, x_t$.

**Initial condition:** $h_0 = \mathbf{0}$ (zero vector).

<LongQuestion>
### Q5 / Q9. Briefly explain the vanishing gradient problem. / Explain in detail the vanishing and exploding gradient problems in RNN training.
</LongQuestion>

RNNs are trained using **Backpropagation Through Time (BPTT)**, which unrolls the network across $T$ time steps. The gradient of the loss w.r.t. early weights involves repeated multiplication:

$$\frac{\partial \mathcal{L}}{\partial W} \propto \prod_{t=1}^{T} \frac{\partial h_t}{\partial h_{t-1}} = \prod_{t=1}^{T} W_{hh}^\top \cdot \text{diag}(f'(h_t))$$

**Vanishing Gradient:**

If $\|W_{hh}\| < 1$ or $|f'| \ll 1$ (e.g., saturated sigmoid/tanh), the product of gradients shrinks exponentially:

$$\left\|\prod_{t=1}^{T} \frac{\partial h_t}{\partial h_{t-1}}\right\| \rightarrow 0 \quad \text{as } T \rightarrow \infty$$

- <Highlight color="red">**Effect:**</Highlight> Early time steps receive near-zero gradients → network cannot learn long-range dependencies.

**Exploding Gradient:**

If $\|W_{hh}\| > 1$, the product grows exponentially.

- <Highlight color="red">**Effect:**</Highlight> Gradients become very large → unstable training, NaN weights.
- <Highlight color="green">**Fix:**</Highlight> **Gradient clipping** — cap gradients if their norm exceeds a threshold.

| Problem | Cause | Effect | Fix |
|---------|-------|--------|-----|
| Vanishing | $\|W_{hh}\| < 1$ or saturated activation | Cannot learn long-term dependencies | LSTM, GRU, ReLU activation |
| Exploding | $\|W_{hh}\| > 1$ | Unstable training, NaN | Gradient clipping |

### Q6 / Q13. Explain the concept of "unrolling" an RNN in time. / Numerical: Given $W_{hh}=0.2$, $W_{xh}=0$, $b_h=0$, $h_0=0$, show the first two steps of unrolling and calculate hidden states.
</LongQuestion>

**Unrolling:**

<Highlight color="blue">**Unrolling**</Highlight> (or unfolding) means expanding the RNN across time steps to visualize it as a deep feedforward network — one copy of the RNN cell per time step. This allows standard backpropagation to be applied (BPTT).

```
h₀ → [Cell, x₁] → h₁ → [Cell, x₂] → h₂ → [Cell, x₃] → h₃
```

Each cell shares the same weights $W_{xh}$, $W_{hh}$, $b_h$.

$$h_1 = \tanh(0 \cdot 1 + 0.2 \cdot 0 + 0) = \tanh(0) = \boxed{0}$$

**Step 2** ($t=2$, $x_2 = 1$):

$$h_2 = \tanh(0 \cdot 1 + 0.2 \cdot 0 + 0) = \tanh(0) = \boxed{0}$$

Since $W_{xh} = 0$ and $h_0 = 0$, the hidden state remains zero — illustrating that input weights must be non-zero for the network to respond to inputs.

# Module 5 — Autoencoders

<LongQuestion>
### Q1 / Q6. What is the purpose of an Autoencoder? What are its key components? / Explain the function of autoencoder using encoder and decoder.
</LongQuestion>

An <Highlight color="blue">**Autoencoder**</Highlight> is an unsupervised neural network trained to **reconstruct its input** at the output layer. Its purpose is to learn a compact, efficient internal representation (encoding) of the data.

**Key components:**

```
Input x → [Encoder] → Latent z → [Decoder] → Reconstruction x̂
```

**1. <Highlight color="green">Encoder</Highlight>:** Maps high-dimensional input $x$ to a low-dimensional latent space $z$:

$$z = f_\theta(x) = \sigma(W_e x + b_e)$$

**2. <Highlight color="orange">Latent Space (Bottleneck)</Highlight>:** Compressed representation $z$ — forces the network to learn the most important features.

**3. <Highlight color="blue">Decoder</Highlight>:** Reconstructs the input from the latent representation:

$$\hat{x} = g_\phi(z) = \sigma(W_d z + b_d)$$

**Training objective** — minimize reconstruction loss:

$$\mathcal{L} = \|x - \hat{x}\|^2 \quad \text{(MSE)}$$

**Applications:** Dimensionality reduction, denoising, anomaly detection, generative modeling.

---

<LongQuestion>
### Q2 / Q3. Describe the characteristics and limitations of linear autoencoders. / What transformation does a linear autoencoder perform?
</LongQuestion>

A <Highlight color="blue">**linear autoencoder**</Highlight> uses only linear activation functions (no non-linearity) throughout.

**Transformation performed:**

$$z = W_e x, \qquad \hat{x} = W_d z = W_d W_e x$$

The overall mapping is: $\hat{x} = (W_d W_e)\,x$ — a **linear transformation** of $x$.

**Characteristics:**
- Encoder and decoder are purely linear layers.
- The bottleneck performs dimensionality reduction via a linear projection.
- It is mathematically equivalent to **PCA (Principal Component Analysis)** — the subspace spanned by the encoder weights converges to the principal components.

**Limitations:**
- <Highlight color="red">**Cannot capture non-linear structure**</Highlight> in data — fails on manifolds and complex distributions.
- <Highlight color="red">**Limited representational power:**</Highlight> Composed linear layers are still just a single linear map.
- <Highlight color="red">**Sensitive to outliers:**</Highlight> MSE loss amplifies large deviations.
- For non-linear data, non-linear autoencoders (with ReLU/tanh) are required.

<LongQuestion>
### Q4 / Q12. What is an undercomplete autoencoder and why is it used? / Compare undercomplete and overcomplete autoencoders.
</LongQuestion>

| Property | Undercomplete | Overcomplete |
|----------|--------------|--------------|
| **Latent dimension** | $\dim(z) < \dim(x)$ | $\dim(z) \geq \dim(x)$ |
| **Constraint** | Bottleneck forces compression | No compression; needs regularization |
| **Goal** | Learn the most important features | Learn a richer, over-parameterized representation |
| **Risk** | Loses fine-grained information | Can learn identity mapping (trivial solution) |
| **Regularization needed** | Not necessary | Required (L1 sparsity, denoising, dropout) |
| **Use case** | Dimensionality reduction, compression | Sparse coding, feature learning, denoising |

**Undercomplete autoencoder:** The hidden layer is smaller than the input — compression forces the encoder to capture only the most salient features.

$$\dim(z) < \dim(x) \Rightarrow \text{bottleneck constraint}$$

Without regularization, an overcomplete autoencoder can copy the input directly to the output, learning nothing useful.

<LongQuestion>
### Q5 / Q15 / Q7. Describe the denoising autoencoder. / Compare denoising and sparse autoencoders. / What is the benefit of using sparse autoencoders?
</LongQuestion>

**Denoising Autoencoder:**

A <Highlight color="blue">**denoising autoencoder (DAE)**</Highlight> is trained to reconstruct the **clean input** $x$ from a **corrupted version** $\tilde{x}$:

$$\tilde{x} = x + \epsilon, \quad \epsilon \sim \mathcal{N}(0, \sigma^2)$$

$$\mathcal{L}_{DAE} = \|x - \hat{x}\|^2 \quad \text{where } \hat{x} = g_\phi(f_\theta(\tilde{x}))$$

The model learns robust features that are invariant to noise.

**Sparse Autoencoder:**

A <Highlight color="blue">**sparse autoencoder**</Highlight> adds a sparsity penalty on the latent representation $z$ so that only a few neurons are active at once:

$$\mathcal{L}_{sparse} = \|x - \hat{x}\|^2 + \lambda \|z\|_1$$

**Benefit of sparsity:** Only a small number of hidden units activate per input → learns **disentangled, interpretable features** (similar to how the brain encodes information).

**Comparison:**

| Property | Denoising AE | Sparse AE |
|----------|-------------|-----------|
| **Goal** | Robustness to corruption | Sparse, interpretable features |
| **How regularized** | Corrupted input during training | L1 penalty on latent $z$ |
| **Overcomplete?** | Can be | Usually overcomplete |
| **Key benefit** | Learns stable features | Feature selection, interpretability |

<LongQuestion>
### Q8 / Q9 / Q13 / Q14. Why is regularization in autoencoders required? Explain two common regularization techniques (L1, L2, Dropout).
</LongQuestion>

**Why regularization is required:**

Without regularization (especially in overcomplete autoencoders), the network learns the **identity function** — simply copying input to output without learning any meaningful representation. Regularization prevents this by constraining the latent space.

**1. <Highlight color="green">L1 Regularization (Sparse Autoencoder)</Highlight>**

$$\mathcal{L} = \|x - \hat{x}\|^2 + \lambda \sum_j |z_j|$$

- Encourages most latent units to be zero → **sparse** representations.
- Promotes feature selection: only important features activate.
- Useful for learning parts-based or disentangled representations.

**2. <Highlight color="orange">L2 Regularization</Highlight>**

$$\mathcal{L} = \|x - \hat{x}\|^2 + \lambda \sum_j z_j^2$$

- Penalizes large activations in the latent space.
- Spreads information across all latent units rather than concentrating it.
- Prevents any single latent dimension from dominating.

**3. <Highlight color="blue">Dropout</Highlight>**

Randomly zeros out a fraction $p$ of latent units during training:

$$z' = z \odot m, \quad m_i \sim \text{Bernoulli}(1-p)$$

- Forces the decoder to reconstruct from incomplete representations.
- Improves robustness and generalization.
- Acts similarly to denoising in the latent space.

<LongQuestion>
### Q10 / Q11. Explain the training process of an autoencoder, including the loss function. / How do autoencoders perform dimensionality reduction?
</LongQuestion>

**Training Process:**

1. **Forward pass:** Input $x$ is passed through encoder → latent $z$ → decoder → reconstruction $\hat{x}$.

2. **Loss computation (MSE):**

$$\mathcal{L} = \frac{1}{n}\sum_{i=1}^{n}\|x^{(i)} - \hat{x}^{(i)}\|^2$$

3. **Backpropagation:** Gradients of $\mathcal{L}$ w.r.t. all weights ($W_e, W_d, b_e, b_d$) are computed.

4. **Weight update:**

$$W \leftarrow W - \eta\,\frac{\partial \mathcal{L}}{\partial W}$$

5. **Repeat** for multiple epochs until reconstruction loss converges.

**Note:** No labels are required — autoencoders are **self-supervised** (the target is the input itself).

**Dimensionality Reduction:**

The encoder maps $x \in \mathbb{R}^d$ to $z \in \mathbb{R}^k$ where $k \ll d$ (undercomplete):

$$z = f_\theta(x): \mathbb{R}^d \rightarrow \mathbb{R}^k$$

- The bottleneck forces the network to retain only the **most informative features**.
- $z$ can be used as a low-dimensional feature vector (similar to PCA but non-linear).
- The decoder verifies that $z$ captures enough information by reconstructing $x$.

**Advantage over PCA:** Autoencoders can learn **non-linear** dimensionality reductions, capturing complex manifold structures that PCA misses.

### Q16. Given input $x = [2, 4, 6]$ and encoder matrix $W_e = \begin{bmatrix}0.5 & 0 \\ 0 & 0.2 \\ 0 & 0\end{bmatrix}$, calculate the latent vector.
</LongQuestion>

**Given:**

$$x = [2,\; 4,\; 6], \qquad W_e = \begin{bmatrix}0.5 & 0 \\ 0 & 0.2 \\ 0 & 0\end{bmatrix}$$

**Formula (linear encoder):**

$$z = x\, W_e$$

**Substitution:**

$$[2\;\; 4\;\; 6]\begin{bmatrix}0.5 & 0 \\ 0 & 0.2 \\ 0 & 0\end{bmatrix} = [z_1,\; z_2]$$

$$z_1 = 2(0.5) + 4(0) + 6(0) = 1.0$$

$$z_2 = 2(0) + 4(0.2) + 6(0) = 0.8$$

**Final Answer:**

$$\boxed{z = [1.0,\; 0.8]}$$

The input is compressed from 3 dimensions to 2 — performing linear dimensionality reduction.

### Q2. What is WaveNet? How is it used for audio generation? <QuestionDot color="purple" text="IA2-QB" />
</LongQuestion>

<Highlight color="blue">**WaveNet**</Highlight> is a deep learning model that generates raw audio waveforms directly. It was introduced by DeepMind and is mainly used to produce natural-sounding speech.

Basic working (easy explanation):

1. WaveNet does not generate full audio at once. It predicts sound <Highlight color="green">**one sample at a time**</Highlight>.
2. It uses <Highlight color="orange">**causal convolutions**</Highlight>, so the current output depends only on past samples (not future samples).
3. It uses <Highlight color="orange">**dilated convolutions**</Highlight> to capture longer context in speech without making the network very deep.
4. This step-by-step prediction continues until a complete waveform is formed.
5. During training, it learns pronunciation, pitch, and rhythm patterns from real audio data.

Applications:

- High-quality text-to-speech (assistants, audiobooks).
- Speech vocoders in modern TTS systems.
- Neural music and general audio generation.

In short, WaveNet is important because it produces clearer and more human-like audio than many older approaches.

### Q3. Describe the concept of Word2Vec in Natural Language Processing. <QuestionDot color="purple" text="IA2-QB" />
</LongQuestion>

<Highlight color="blue">**Word2Vec**</Highlight> converts words into numeric vectors so that words with similar meanings end up close to each other in vector space.

For example: king − man + woman ≈ queen. This shows the model understands word relationships without being explicitly taught.

#### Two Architectures

1. <Highlight color="green">**CBOW (Continuous Bag of Words):**</Highlight> Predicts a center word from its surrounding words.
2. <Highlight color="green">**Skip-gram:**</Highlight> Predicts surrounding words given a center word. Works better for rare words.

#### Efficiency Tricks

- <Highlight color="orange">**Negative Sampling:**</Highlight> Instead of updating all words, only update a small random set of incorrect words per step.
- <Highlight color="orange">**Hierarchical Softmax:**</Highlight> Uses a tree structure to speed up probability calculation.

#### Applications

- Text classification and sentiment analysis
- Named entity recognition
- Pretrained embeddings for NLP models

### Q4. How is deep learning applied in face recognition systems? <QuestionDot color="purple" text="IA2-QB" />
</LongQuestion>

Deep learning-based face recognition converts a face image into a numerical identity representation called an <Highlight color="blue">**embedding**</Highlight>, then compares embeddings to recognize a person.

#### Standard Pipeline

1. <Highlight color="green">**Face Detection:**</Highlight> Detect face region from full image/video frame.
2. <Highlight color="green">**Face Alignment:**</Highlight> Normalize rotation/scale using landmarks (eyes, nose, mouth).
3. <Highlight color="green">**Feature Extraction:**</Highlight> CNN/Transformer model (for example FaceNet, ArcFace-style backbones) produces a compact embedding vector.
4. <Highlight color="green">**Similarity Matching:**</Highlight> Compare with stored embeddings using cosine similarity or Euclidean distance.
5. <Highlight color="green">**Decision:**</Highlight>
   - Verification (1:1): "Is this claimed identity correct?"
   - Identification (1:N): "Who is this person in database?"

#### Training Logic

Models are trained so embeddings of the same person are close and different persons are far apart using:

1. <Highlight color="orange">Contrastive Loss</Highlight>
2. <Highlight color="orange">Triplet Loss</Highlight>
3. <Highlight color="orange">Margin-based losses (ArcFace/CosFace family)</Highlight>

#### Real Applications

1. Phone unlock and attendance systems
2. Access control and surveillance analytics
3. Photo clustering/tagging in media apps

Thus, deep learning enables robust face recognition under variations in pose, lighting, and expression by learning discriminative embeddings.

### Q5. Define semantic segmentation with an example. <QuestionDot color="purple" text="IA2-QB" />
</LongQuestion>

<Highlight color="blue">**Semantic segmentation**</Highlight> means <Highlight color="green">**classifying every single pixel in an image into a category**</Highlight> (e.g. road, car, person, sky).

The output is a colored mask the same size as the input image, where each pixel is colored based on its class.

#### Key Points

1. Works at pixel level — much more detailed than classification.
2. All objects of the same class get the same label (no distinction between individuals).
3. Uses encoder-decoder networks like FCN, U-Net, and DeepLab.
4. Measured using IoU / mIoU metrics.

#### Semantic vs Instance Segmentation

- **Semantic:** Two cars → both labeled "car" (same color).
- **Instance:** Two cars → labeled "car-1" and "car-2" separately.

#### Example

In a self-driving car, semantic segmentation labels every pixel as road, pedestrian, vehicle, or sky. This helps the car understand its surroundings and plan a safe path.

### Q6. What is automated image captioning? Explain its basic working. / What is Automated Image Captioning? Explain how Deep Learning is used in it. <QuestionDot color="purple" text="IA2-QB" />
</LongQuestion>

<Highlight color="blue">**Automated image captioning**</Highlight> is the task of generating a meaningful natural-language sentence for an input image. It combines <Highlight color="green">computer vision</Highlight> and <Highlight color="green">sequence generation</Highlight>.

#### How Deep Learning Is Used

1. <Highlight color="orange">**Visual Encoder**</Highlight> (CNN/ViT): extracts semantic visual features such as objects, attributes, and scene context.
2. <Highlight color="orange">**Language Decoder**</Highlight> (LSTM/GRU/Transformer): generates words one by one based on encoded image features.
3. <Highlight color="orange">**Attention Mechanism**</Highlight>: lets the decoder focus on relevant regions while predicting each next word.
4. <Highlight color="orange">**Sequence Modeling**</Highlight>: generation continues until an end token is produced.

#### Training and Inference

During training, the model learns to maximize likelihood of the reference caption token-by-token (cross-entropy objective).

During inference, decoding can be done using:

1. Greedy decoding
2. Beam search (often yields better captions)

#### Example and Applications

Example caption: "A person riding a bike on a road."

Applications include assistive technology for visually impaired users, automatic media indexing, and smart photo search systems.

### Q7. Differentiate between image classification and object detection. <QuestionDot color="purple" text="IA2-QB" /> <QuestionDot color="purple" text="Asked in IA2" />
</LongQuestion>

- <Highlight color="blue">**Image classification:**</Highlight> Tells *what* is in the image (one label for the whole image).
- <Highlight color="blue">**Object detection:**</Highlight> Tells *what* objects are in the image *and where* each one is (bounding box + label).

| Basis | Image Classification | Object Detection |
|------|----------------------|------------------|
| Task | Label the whole image | Label + locate each object |
| Output | Class label + probability | Bounding box + label + confidence |
| Localization | Not needed | Required |
| Training labels | Image-level | Box-level (x, y, width, height) |
| Metrics | Accuracy, Top-1/5 | mAP, IoU |
| Models | ResNet, VGG, ViT | YOLO, Faster R-CNN, SSD |
| Complexity | Simpler | More complex |

#### Example

For a road image with 2 cars and 1 pedestrian:
- **Classification output:** "Road scene with vehicles"
- **Detection output:** Draws a box around each car and the pedestrian with labels and confidence scores.

**Conclusion:** Use classification when you only need to know what's in the image. Use detection when you need to know where each object is.
