# Module 1

<LongQuestion>
### Q6. Numerical: Given a perceptron with weights $w=[0.7,−0.4]$, bias $b=0.1$, and input $x=[2,1]$, calculate the output using a step activation function.
</LongQuestion>

**Step 1 — Compute weighted sum:**

$$z = w_1 x_1 + w_2 x_2 + b = (0.7)(2) + (-0.4)(1) + 0.1$$

$$z = 1.4 - 0.4 + 0.1 = \mathbf{1.1}$$

**Step 2 — Apply step activation function:**

$$\text{Output} = \begin{cases} 1 & \text{if } z > 0 \\ 0 & \text{if } z \leq 0 \end{cases}$$

Since $z = 1.1 > 0$:

$$\boxed{y = 1}$$

<LongQuestion>
### Q14. Numerical: Calculate the output of the given neural network (Sigmoid, 2→2→1 architecture).
</LongQuestion>

**Given:**
- Input: $x = [1, 0]$
- $W_1 = \begin{bmatrix}0.9 & 0.6 \\ -0.4 & 0.1\end{bmatrix}$, $b_1 = [0.3,\,-0.1]$
- $W_2 = [0.6,\,-0.5]$, $b_2 = 0.5$

**Step 1 — Hidden layer pre-activation:**

$$z_1^{[1]} = 0.9(1) + (-0.4)(0) + 0.3 = 1.2$$
$$z_2^{[1]} = 0.6(1) + 0.1(0) + (-0.1) = 0.5$$

**Step 2 — Hidden layer activation (Sigmoid):**

$$a_1^{[1]} = \sigma(1.2) = \frac{1}{1+e^{-1.2}} \approx \mathbf{0.7685}$$
$$a_2^{[1]} = \sigma(0.5) = \frac{1}{1+e^{-0.5}} \approx \mathbf{0.6225}$$

**Step 3 — Output layer pre-activation:**

$$z^{[2]} = 0.6(0.7685) + (-0.5)(0.6225) + 0.5$$
$$= 0.4611 - 0.3113 + 0.5 = 0.6498$$

**Step 4 — Output activation (Sigmoid):**

$$\hat{y} = \sigma(0.6498) = \frac{1}{1+e^{-0.6498}} \approx \boxed{0.6570}$$

# Module 3

<LongQuestion>
### Q3. Provide a numerical example of how a perceptron can perform binary classification.
</LongQuestion>

**Given:** Weights $w = [0.5,\; -0.3]$, bias $b = 0.1$, input $x = [1,\; 2]$, step activation.

**Step 1 — Weighted sum:**

$$z = w_1 x_1 + w_2 x_2 + b = (0.5)(1) + (-0.3)(2) + 0.1$$

$$z = 0.5 - 0.6 + 0.1 = 0.0$$

**Step 2 — Step activation:**

$$\hat{y} = \begin{cases} 1 & z > 0 \\ 0 & z \leq 0 \end{cases}$$

Since $z = 0 \leq 0$:

$$\boxed{\hat{y} = 0 \quad \text{(Class 0)}}$$

**Interpretation:** The perceptron separates two classes using the hyperplane $w^T x + b = 0$. Points on one side are Class 1, the other side Class 0.

<LongQuestion>
### Q6 / Q13. Explain the concept of "unrolling" an RNN in time. / Numerical: Given $W_{hh}=0.2$, $W_{xh}=0$, $b_h=0$, $h_0=0$, show the first two steps of unrolling and calculate hidden states.
</LongQuestion>

**Unrolling:**

<Highlight color="blue">**Unrolling**</Highlight> (or unfolding) means expanding the RNN across time steps to visualize it as a deep feedforward network — one copy of the RNN cell per time step. This allows standard backpropagation to be applied (BPTT).

```
h₀ → [Cell, x₁] → h₁ → [Cell, x₂] → h₂ → [Cell, x₃] → h₃
```

Each cell shares the same weights $W_{xh}$, $W_{hh}$, $b_h$.

**Numerical (assume input sequence $x = [1, 1, 1, \ldots]$):**

**Given:** $W_{hh} = 0.2$, $W_{xh} = 0$, $b_h = 0$, $h_0 = 0$

$$h_t = \tanh(W_{xh}\,x_t + W_{hh}\,h_{t-1} + b_h)$$

**Step 1** ($t=1$, $x_1 = 1$):

$$h_1 = \tanh(0 \cdot 1 + 0.2 \cdot 0 + 0) = \tanh(0) = \boxed{0}$$

**Step 2** ($t=2$, $x_2 = 1$):

$$h_2 = \tanh(0 \cdot 1 + 0.2 \cdot 0 + 0) = \tanh(0) = \boxed{0}$$

Since $W_{xh} = 0$ and $h_0 = 0$, the hidden state remains zero — illustrating that input weights must be non-zero for the network to respond to inputs.

<LongQuestion>
### Q10. A sparse autoencoder uses L1 regularization with $\lambda = 0.1$. The latent representation is $h = [0.5,\,-0.2,\,0.8]$. Calculate the L1 regularization term.
</LongQuestion>

**Given:**

$$\lambda = 0.1, \quad h = [0.5,\; -0.2,\; 0.8]$$

**Formula (L1 regularization term):**

$$\mathcal{R}_{L1} = \lambda \sum_i |h_i|$$

**Calculation:**

$$\sum_i |h_i| = |0.5| + |-0.2| + |0.8| = 0.5 + 0.2 + 0.8 = 1.5$$

$$\mathcal{R}_{L1} = 0.1 \times 1.5 = \boxed{0.15}$$

This term is added to the reconstruction loss to encourage sparsity in the latent representation.

<LongQuestion>
### Q11. RNN forward pass numerical: $W_{hh}=0.4$, $W_{xh}=0.2$, $W_{hy}=0.6$, $b_h=0.1$, $b_y=0.2$, input $x=[1, 2]$, $h_0=0$. (a) Calculate $h_1, h_2, y_1, y_2$. (b) Error at $t=2$ if target $y_2^* = 1$.
</LongQuestion>

**Given:**

$$W_{hh}=0.4,\; W_{xh}=0.2,\; W_{hy}=0.6,\; b_h=0.1,\; b_y=0.2,\; h_0=0$$

$$\text{Input: } x_1=1,\; x_2=2$$

**Formula:**

$$h_t = \tanh(W_{xh}\,x_t + W_{hh}\,h_{t-1} + b_h), \qquad y_t = W_{hy}\,h_t + b_y$$

**(a) Step 1** ($t=1$):

$$h_1 = \tanh(0.2 \times 1 + 0.4 \times 0 + 0.1) = \tanh(0.3) \approx \mathbf{0.2913}$$

$$y_1 = 0.6 \times 0.2913 + 0.2 = 0.1748 + 0.2 = \boxed{0.3748}$$

**Step 2** ($t=2$):

$$h_2 = \tanh(0.2 \times 2 + 0.4 \times 0.2913 + 0.1) = \tanh(0.4 + 0.1165 + 0.1) = \tanh(0.6165) \approx \mathbf{0.5490}$$

$$y_2 = 0.6 \times 0.5490 + 0.2 = 0.3294 + 0.2 = \boxed{0.5294}$$

**(b) Error at $t=2$:**

$$e_2 = y_2^* - y_2 = 1 - 0.5294 = \boxed{0.4706}$$

<LongQuestion>
### Q12. Given $W_{hh}=0.5$, $W_{xh}=0.3$, $b_h=0.1$, $x_t=2$, $h_{t-1}=1$. Calculate $h_t$ using tanh.
</LongQuestion>

**Given:**

$$W_{hh}=0.5,\quad W_{xh}=0.3,\quad b_h=0.1,\quad x_t=2,\quad h_{t-1}=1$$

**Formula:**

$$h_t = \tanh(W_{xh}\,x_t + W_{hh}\,h_{t-1} + b_h)$$

**Substitution:**

$$h_t = \tanh(0.3 \times 2 + 0.5 \times 1 + 0.1) = \tanh(0.6 + 0.5 + 0.1) = \tanh(1.2)$$

$$h_t = \frac{e^{1.2} - e^{-1.2}}{e^{1.2} + e^{-1.2}} \approx \boxed{0.8337}$$

### Q16. Given input $x = [2, 4, 6]$ and encoder matrix $W_e = \begin{bmatrix}0.5 & 0 \\ 0 & 0.2 \\ 0 & 0\end{bmatrix}$, calculate the latent vector.
</LongQuestion>

**Given:**

$$x = [2,\; 4,\; 6], \qquad W_e = \begin{bmatrix}0.5 & 0 \\ 0 & 0.2 \\ 0 & 0\end{bmatrix}$$

**Formula (linear encoder):**

$$z = x\, W_e$$

**Substitution:**

$$[2\;\; 4\;\; 6]\begin{bmatrix}0.5 & 0 \\ 0 & 0.2 \\ 0 & 0\end{bmatrix} = [z_1,\; z_2]$$

$$z_1 = 2(0.5) + 4(0) + 6(0) = 1.0$$

$$z_2 = 2(0) + 4(0.2) + 6(0) = 0.8$$

**Final Answer:**

$$\boxed{z = [1.0,\; 0.8]}$$

The input is compressed from 3 dimensions to 2 — performing linear dimensionality reduction.
