# Module 1 - Generalized Linear Models & Exponential Family


### Q1. Explain the <Highlight color="yellow">three GLM components</Highlight> (random, systematic, link) and <Highlight color="yellow">how they interact</Highlight>. / Describe the <Highlight color="yellow">GLM structure</Highlight> and its component roles. <QuestionDot color="yellow" text="IA1-QB" /> <QuestionDot color="cyan" text="MSE-QB" /> <QuestionDot color="purple" text="Asked in MSE" /> <QuestionDot color="red" text="Important" />


A **Generalized Linear Model (GLM)** extends linear regression so that the response variable can follow distributions **other than Normal** (e.g., binary, count data).


A GLM has **three components**:


1. **Random Component**
   The probability distribution of the response variable $Y$, which must belong to the **exponential family** (e.g., Normal, Bernoulli, Poisson).
   $$
   Y \sim \text{Exponential Family}
   $$


2. **Systematic Component**
   A linear combination of input variables (the linear predictor):
   $$
   \eta = \beta_0 + \beta_1 x_1 + \cdots + \beta_p x_p = X\beta
   $$


3. **Link Function**
   Connects the mean $\mu = E(Y)$ to the linear predictor:
   $$
   g(\mu) = \eta
   $$
   It ensures predictions stay within valid range for the chosen distribution.


   Common link functions:
   - **Identity** ($g(\mu) = \mu$) $\rightarrow$ Linear regression
   - **Logit** ($g(\mu) = \log\frac{\mu}{1-\mu}$) $\rightarrow$ Logistic regression
   - **Log** ($g(\mu) = \log(\mu)$) $\rightarrow$ Poisson regression


**Significance:**
GLMs provide a **single framework** for modeling continuous, binary, and count data while keeping the simplicity of linear models.


**How They Interact:**
The random component defines the distribution of $Y$ and its mean $\mu$. The link function bridges $\mu$ to the linear predictor $\eta$. The systematic component builds $\eta$ from the predictors. Together:
$$
\mathbf{X}\boldsymbol{\beta} \overset{\text{Systematic}}{\longrightarrow} \eta \overset{g^{-1}}{\longrightarrow} \mu \overset{\text{Random}}{\longrightarrow} Y
$$

### Q2. Role of the <Highlight color="yellow">canonical link function</Highlight> in <Highlight color="yellow">GLMs</Highlight>? / What are <Highlight color="yellow">link functions</Highlight> and <Highlight color="yellow">why</Highlight> are they used? / Explain link functions in GLMs with an <Highlight color="yellow">example distribution</Highlight>. <QuestionDot color="yellow" text="IA1-QB" /> <QuestionDot color="green" text="Asked in IA1" /> <QuestionDot color="red" text="Important" />


In a **Generalized Linear Model (GLM)**, a <Highlight color="blue">**link function**</Highlight> establishes a relationship between the **expected value of the response variable** and the **linear predictor**.


Mathematically, it is defined as:
$$
g(\mu) = \eta = X\beta
$$
where $\mu = E(y)$ is the mean of the response variable.


The link function transforms $\mu$ so it can be modeled as a linear combination of inputs. This is needed because many response variables have a restricted range (e.g., probabilities must be between 0 and 1).


Different distributions need different link functions:


| Link Function | Formula | Used For |
|---|---|---|
| **Identity** | $g(\mu) = \mu$ | Linear regression (no constraint) |
| **Logit** | $g(\mu) = \log\frac{\mu}{1-\mu}$ | Logistic regression ($\mu$ between 0 and 1) |
| **Log** | $g(\mu) = \log(\mu)$ | Poisson regression ($\mu > 0$) |
| **Probit** | $g(\mu) = \Phi^{-1}(\mu)$ | Binary classification ($\mu$ between 0 and 1) |


**Why are they important?**
1. They keep predictions within the **valid range** for the response variable.
2. They let us use **one GLM framework** for many data types (binary, count, continuous).
3. The **canonical link** (default for each distribution) makes parameter estimation simpler.

### Q3. <Highlight color="yellow">Explain Probit regression</Highlight> and <Highlight color="yellow">compare with Logistic regression</Highlight>. / Compare Probit and Logistic regression: link functions, assumptions, and scenarios. <QuestionDot color="yellow" text="IA1-QB" /> <QuestionDot color="red" text="Important" />


**Probit regression** is a GLM used for binary classification. It models probability using the **standard normal CDF**:
$$
P(y=1 \mid x,w) = \Phi(w^T x)
$$


The link function is:
$$
g(\mu) = \Phi^{-1}(\mu)
$$


---


**Logistic regression** is also a GLM for binary classification. It models probability using the **sigmoid function**:
$$
P(y=1 \mid x,w) = \frac{1}{1 + e^{-w^T x}}
$$


The link function is:
$$
g(\mu) = \log\frac{\mu}{1-\mu}
$$


### Comparison


| Aspect | Probit Regression | Logistic Regression |
|---|---|---|
| Link Function | Probit ($\Phi^{-1}(\mu)$) | Logit ($\log\frac{\mu}{1-\mu}$) |
| Function | Normal CDF | Sigmoid |
| Assumption | Gaussian (normal) noise | Logistic noise |

### Q4. What is <Highlight color="yellow">multitask learning</Highlight>? How does <Highlight color="yellow">parameter sharing</Highlight> enhance generalization with <Highlight color="yellow">scarce data</Highlight>? <QuestionDot color="yellow" text="IA1-QB" /> <QuestionDot color="green" text="Asked in IA1" />


**Multitask Learning (MTL)** trains multiple related tasks **together** in a single model instead of building separate models for each task.


The core idea is <Highlight>**parameter sharing**</Highlight>, which has two types:


1. **Hard Sharing**: Tasks share the same hidden layers, only output layers are separate. Most common and reduces overfitting.
2. **Soft Sharing**: Each task has its own model, but parameters are pushed to stay similar.


**How Parameter Sharing Helps:**
1. **Knowledge Transfer**: Tasks with less data learn from tasks with more data
2. **Regularization**: Shared parameters reduce overfitting, especially for low-data tasks
3. **Better Features**: Model learns general patterns useful across all tasks
4. **Better Generalization**: Learning from multiple tasks makes the model more robust.

# Module 2 - Directed Graphical Models


### Q1. What are <Highlight color="yellow">Directed Graphical Models (Bayesian Networks)</Highlight>? Explain <Highlight color="yellow">causal relationships</Highlight> and <Highlight color="yellow">probabilistic inference</Highlight>. / Define DGMs and how they represent joint probability. <QuestionDot color="yellow" text="IA1-QB" /> <QuestionDot color="cyan" text="MSE-QB" /> <QuestionDot color="purple" text="Asked in MSE" /> <QuestionDot color="red" text="Important" />


**Directed Graphical Models (DGMs)** are probabilistic models that use a **directed graph** to show dependencies between random variables. Each **node** = a variable, each **arrow** = a dependency.


A **Bayesian Network** is a DGM whose graph is a **DAG (Directed Acyclic Graph)** - no cycles.


**Joint Probability Factorization:**
$$
P(X_1, X_2, \dots, X_n) = \prod_{i=1}^{n} P(X_i \mid \text{Parents}(X_i))
$$


**How It Facilitates Inference:**
The graph structure tells us **which variables are relevant** - reducing computation. Instead of needing $2^n-1$ parameters, we only need to store the conditional probability tables for each node and its parents.

### Q2. How do Bayesian Networks use <Highlight color="yellow">conditional independence</Highlight>? Explain <Highlight color="yellow">three structures</Highlight> with examples. / Explain conditional independence in DGMs with <Highlight color="yellow">graphical intuition</Highlight>. <QuestionDot color="yellow" text="IA1-QB" /> <QuestionDot color="cyan" text="MSE-QB" /> <QuestionDot color="purple" text="Asked in MSE" /> <QuestionDot color="red" text="Important" />


**Conditional independence** means two variables don't affect each other once we know a third variable: $X \perp Y \mid Z$.


**Three Basic Structures:**


1. **Chain:** $A \to B \to C$
   - $A \perp C \mid B$
   - Observing $B$ **blocks** the path. Example: Smoking $\rightarrow$ Tar $\rightarrow$ Cancer.


2. **Fork:** $B \leftarrow A \to C$
   - $B \perp C \mid A$
   - Observing common cause $A$ **blocks** the path. Example: Season $\rightarrow$ Rain, Season $\rightarrow$ Sprinkler.


3. **Collider:** $A \rightarrow B \leftarrow C$
   - $A \perp C$ marginally, but **NOT** given $B$.
   - Observing $B$ **opens** the path (explaining away). Example: Intelligence $\rightarrow$ Grades $\leftarrow$ Study Hours.

### Q5. What is a <Highlight color="yellow">Directed Gaussian Graphical Model (DGGM)</Highlight>? Explain the <Highlight color="yellow">Gaussian distribution assumption</Highlight>.


A **DGGM** is a Bayesian Network where **all variables follow a Gaussian distribution**. The conditional probability distributions are **linear Gaussian**:
$$
p(x_t \mid \text{parents}) = \mathcal{N}(\mu_t + \mathbf{w}_t^T x_{\text{parents}},\ \sigma_t^2)
$$


**The Gaussian Assumption:**
When all CPDs are Gaussian, their product results in a **single joint multivariate Gaussian**. This allows for **exact (closed-form) solutions** for inference and makes computation very efficient.

# Module 3 - Mixture Models & EM Algorithm


### Q1. <Highlight color="yellow">Derive MLE</Highlight> for <Highlight color="yellow">mean and variance</Highlight> of a univariate <Highlight color="yellow">Gaussian distribution</Highlight>. <QuestionDot color="red" text="Important" />


Given $y_1, \dots, y_N \sim \mathcal{N}(\mu, \sigma^2)$. The log-likelihood is:
$$
\ell = -\frac{N}{2}\log(\sigma^2) - \frac{1}{2\sigma^2}\sum (y_i - \mu)^2
$$


**1. For $\mu$:**
$$
\frac{\partial \ell}{\partial \mu} = \frac{1}{\sigma^2}\sum (y_i - \mu) = 0 \Rightarrow \hat{\mu} = \frac{1}{N}\sum y_i
$$


**2. For $\sigma^2$:**
$$
\frac{\partial \ell}{\partial \sigma^2} = 0 \Rightarrow \hat{\sigma}^2 = \frac{1}{N}\sum (y_i - \mu)^2
$$

### Q2. What is a <Highlight color="yellow">Gaussian Mixture Model (GMM)</Highlight>? Write its <Highlight color="yellow">PDF with K components</Highlight>. <QuestionDot color="cyan" text="MSE-QB" /> <QuestionDot color="red" text="Important" />


A **GMM** represents data as a **combination of multiple Gaussian distributions**. It performs **soft clustering**, assigning data points to clusters with probabilities.


The PDF is:
$$
p(x) = \sum_{k=1}^{K} \pi_k \, \mathcal{N}(x \mid \mu_k, \Sigma_k)
$$


Where $\pi_k$ are mixing coefficients, such that $\sum \pi_k = 1$ and $0 \le \pi_k \le 1$.

### Q3. Steps of the <Highlight color="yellow">EM algorithm</Highlight> and why they are crucial for <Highlight color="yellow">parameter estimation</Highlight>. / Explain <Highlight color="yellow">E-step and M-step</Highlight> and why it <Highlight color="yellow">guarantees convergence</Highlight>. <QuestionDot color="cyan" text="MSE-QB" /> <QuestionDot color="purple" text="Asked in MSE" /> <QuestionDot color="red" text="Important" />


The **EM Algorithm** is used when data has **latent (hidden) variables**.


1. **E-step (Expectation):** Calculate the **responsibility** $\gamma_{nk}$ (probability that point $n$ belongs to cluster $k$) using current parameters.
2. **M-step (Maximization):** Update parameters ($\mu, \Sigma, \pi$) to maximize the likelihood using the responsibilities.


**Why needed:** If labels were known, MLE would be simple. Hidden labels make direct optimization impossible; EM alternates to find a local optimum.
**Convergence:** Likelihood is guaranteed to increase or stay the same at every iteration.

### Q2. Define <Highlight color="yellow">transition and emission probabilities</Highlight> in <Highlight color="yellow">HMMs</Highlight> and their significance.


1. **Transition Probabilities (A):** $a_{ij} = P(q_{t+1}=S_j \mid q_t=S_i)$. Probability of moving between hidden states. Signifies how the system **evolves**.
2. **Emission Probabilities (B):** $b_j(k) = P(O_t=v_k \mid q_t=S_j)$. Probability of an observation given a hidden state. Signifies how states **produce data**.


---


### Q3. Three <Highlight color="yellow">fundamental problems of HMMs</Highlight> and their <Highlight color="yellow">algorithms</Highlight>. <QuestionDot color="red" text="Important" />


1. **Evaluation:** Compute $P(O \mid \lambda)$. Algorithm: **Forward Algorithm**.
2. **Decoding:** Find most likely hidden state sequence. Algorithm: **Viterbi Algorithm**.
3. **Learning:** Estimate model parameters from data. Algorithm: **Baum-Welch (EM)**.

### Q4. <Highlight color="yellow">Forward variable</Highlight> $\alpha_t(i)$ for HMM and <Highlight color="yellow">Forward Algorithm steps</Highlight>. <QuestionDot color="red" text="Important" />


**Forward Variable:** $\alpha_t(i)$ = probability of seeing first $t$ symbols and being in state $S_i$ at time $t$.


**Steps:**
1. **Initialization:** $\alpha_1(i) = \pi_i \cdot b_i(O_1)$
2. **Recursion:** $\alpha_t(j) = [\sum \alpha_{t-1}(i) \cdot a_{ij}] \cdot b_j(O_t)$
3. **Termination:** $P(O \mid \lambda) = \sum \alpha_T(i)$

# Module 5 - Undirected Graphical Models


### Q1. Apply <Highlight color="yellow">conditional independence</Highlight> to <Highlight color="yellow">undirected graphical models</Highlight> (MRF) using chain A-B-C. <QuestionDot color="red" text="Important" />


**MRFs** encode independence through **graph separation**. In a chain $A - B - C$:
- **Factorization:** $P(A,B,C) = \frac{1}{Z} \psi_{AB}(A,B) \cdot \psi_{BC}(B,C)$
- **Global Property:** Node $B$ separates $A$ from $C$, so $A \perp C \mid B$. Once $B$ is known, $A$ and $C$ become independent.

### Q4. <Highlight color="yellow">Define and write formula</Highlight> for <Highlight color="yellow">Markov Random Fields</Highlight>. <QuestionDot color="red" text="Important" />


An **MRF** uses an undirected graph where **no edge** implies conditional independence.


**Formula:** $P(X_1, \dots, X_n) = \frac{1}{Z} \prod_{C \in \mathcal{C}} \psi_C(X_C)$
- $\mathcal{C}$ = set of maximal cliques.
- $\psi_C$ = non-negative potential function.
- $Z$ = partition function.

# Module 6 - Monte Carlo Inference


### Q1. What is <Highlight color="yellow">Monte Carlo Inference</Highlight> and <Highlight color="yellow">why</Highlight> is it used? <QuestionDot color="red" text="Important" />


It uses **random sampling** to approximate complex probability calculations.
**Core Idea:** $\mathbb{E}_p[f(x)] \approx \frac{1}{N} \sum f(x_i), \quad x_i \sim p(x)$.
**Why used:** Analytical solutions are often impossible for high-dimensional integrals or complex distributions with intractable normalization constants.


---


### Q2. <Highlight color="yellow">Rejection Sampling</Highlight> requirements. <QuestionDot color="red" text="Important" />


Samples from target $p(x)$ using proposal $q(x)$ where $M \cdot q(x) \ge p(x)$.
**Requirements:**
- $q(x)$ must be easy to sample from.
- $M \cdot q(x)$ must cover $p(x)$ everywhere.
- Acceptance rate is $\frac{1}{M}$, so $M$ should be small for efficiency.


---


### Q3. Practical <Highlight color="yellow">challenges</Highlight> of <Highlight color="yellow">Metropolis-Hastings</Highlight>.


1. **Proposal Tuning:** Too narrow = slow exploration; too wide = many rejections.
2. **Burn-in:** Initial samples are biased and must be discarded.
3. **Autocorrelation:** Consecutive samples are highly correlated.
4. **Convergence:** Hard to definitively prove the chain has reached the target distribution.


---


### Q4. <Highlight color="yellow">Compare Importance and Rejection Sampling</Highlight>. <QuestionDot color="red" text="Important" />


- **Rejection Sampling:** Produces **actual i.i.d. samples** from the target distribution. Many samples are discarded.
- **Importance Sampling:** Produces a **weighted estimate** of an expectation. No samples are rejected; instead, they are assigned weights $w(x) = p(x)/q(x)$.
