### Q1. Explain the concept of the Exponential Family of Distributions. Discuss its general form and significance.

The **exponential family** is a set of probability distributions that can all be written in one common form. Many well-known distributions belong to this family — **Gaussian, Bernoulli, Binomial, Poisson, and Exponential**.

The general form is:

$$
p(y|\theta) = h(y)\exp\left(\eta(\theta)T(y) - A(\theta)\right)
$$

where:

- $h(y)$: **Base measure** — scaling factor that depends on the data.
- $\eta(\theta)$: **Natural parameter** — controls the shape of the distribution.
- $T(y)$: **Sufficient statistic** — summarizes all information in the data needed to estimate $\theta$.
- $A(\theta)$: **Log-partition function** — ensures the distribution adds up to 1.

**Examples:**

| Distribution | Use Case |
|---|---|
| Bernoulli | Yes/No outcomes |
| Poisson | Count data |
| Gaussian | Continuous data |

**Significance:**

- Provides a **unified framework** for many common distributions.
- Makes parameter estimation easy using **MLE**.
- Forms the **theoretical basis of GLMs**.
- Enables conjugate priors in Bayesian analysis.

### Q2. Describe the structure of a Generalized Linear Model (GLM).

A **Generalized Linear Model (GLM)** extends linear regression so that the response variable can follow distributions **other than Normal** (e.g., binary, count data).

A GLM has **three components**:

1. **Random Component**
   
   The probability distribution of the response variable $Y$, which must belong to the **exponential family** (e.g., Normal, Bernoulli, Poisson).
   $$
   Y \sim \text{Exponential Family}
   $$

2. **Systematic Component**
   
   A linear combination of input variables (the linear predictor):
   $$
   \eta = \beta_0 + \beta_1 x_1 + \cdots + \beta_p x_p = X\beta
   $$

3. **Link Function**
   
   Connects the mean $\mu = E(Y)$ to the linear predictor:
   $$
   g(\mu) = \eta
   $$
   It ensures predictions stay within valid range for the chosen distribution.

   Common link functions:
   - **Identity** ($g(\mu) = \mu$) → Linear regression
   - **Logit** ($g(\mu) = \log\frac{\mu}{1-\mu}$) → Logistic regression
   - **Log** ($g(\mu) = \log(\mu)$) → Poisson regression

**Significance:**

GLMs provide a **single framework** for modeling continuous, binary, and count data while keeping the simplicity of linear models. They are widely used in statistics, ML, and economics.

### Q3. What are link functions in GLMs? Why are different link functions used?

In a **Generalized Linear Model (GLM)**, a <Highlight color="blue">**link function**</Highlight> establishes a relationship between the **expected value of the response variable** and the **linear predictor**.

Mathematically, it is defined as:
$$
g(\mu) = \eta = X\beta
$$
where $\mu = E(y)$ is the mean of the response variable.

The link function transforms $\mu$ so it can be modeled as a linear combination of inputs. This is needed because many response variables have a restricted range (e.g., probabilities must be between 0 and 1).

Different distributions need different link functions:

| Link Function | Formula | Used For |
|---|---|---|
| **Identity** | $g(\mu) = \mu$ | Linear regression (no constraint) |
| **Logit** | $g(\mu) = \log\frac{\mu}{1-\mu}$ | Logistic regression ($\mu$ between 0 and 1) |
| **Log** | $g(\mu) = \log(\mu)$ | Poisson regression ($\mu > 0$) |
| **Probit** | $g(\mu) = \Phi^{-1}(\mu)$ | Binary classification ($\mu$ between 0 and 1) |

**Why are they important?**

1. They keep predictions within the **valid range** for the response variable.
2. They let us use **one GLM framework** for many data types (binary, count, continuous).
3. The **canonical link** (default for each distribution) makes parameter estimation simpler.

Thus, link functions provide <Highlight>**flexibility**</Highlight>, ensure valid predictions, and allow linear models to handle a wide variety of response variables.

### Q4. Explain Probit regression and compare it conceptually with Logistic regression.

**Probit regression** is used for binary classification (output is 0 or 1). It models the probability using the **CDF of the standard normal distribution**.

$$
P(y=1|x) = \Phi(X\beta)
$$
where $\Phi(\cdot)$ is the standard normal CDF.

It assumes a hidden <Highlight color="blue">**latent variable**</Highlight> $y^*$ that follows a normal distribution. If $y^*$ crosses a threshold, the outcome is 1:
$$
y = \begin{cases} 1 & \text{if } y^* > 0 \\ 0 & \text{otherwise} \end{cases}
$$

**Comparison with Logistic Regression:**

| Feature | Probit | Logistic |
|---|---|---|
| **Link Function** | Inverse normal CDF ($\Phi^{-1}$) | Logit ($\log\frac{p}{1-p}$) |
| **Probability** | $\Phi(X\beta)$ | $\frac{1}{1+e^{-X\beta}}$ |
| **Error Distribution** | Normal | Logistic |
| **Tails** | Lighter (approaches 0/1 faster) | Heavier |
| **Interpretability** | Less intuitive | Coefficients = log-odds (easier) |

In practice, both give **very similar results**. Logistic regression is more popular because of easier interpretation, while probit is preferred in econometrics.

### Q5. Discuss Multitask Learning (MTL). How does parameter sharing improve learning performance and generalization?

**Multitask Learning (MTL)** trains multiple related tasks **together** in a single model instead of building separate models for each task.

The core idea is <Highlight>**parameter sharing**</Highlight>, which has two types:

1. **Hard Sharing**: Tasks share the same hidden layers, only output layers are separate. Most common and reduces overfitting.
2. **Soft Sharing**: Each task has its own model, but parameters are pushed to stay similar.

**How Parameter Sharing Helps:**

1. **Knowledge Transfer**: Tasks with less data learn from tasks with more data.
2. **Regularization**: Shared layers prevent overfitting to any single task.
3. **Better Features**: Model learns general patterns useful across all tasks.
4. **Better Generalization**: Learning from multiple tasks makes the model more robust.

**Examples:**

- **NLP**: One model doing NER + POS tagging + sentiment analysis together.
- **Vision**: One model doing object detection + segmentation + depth estimation.
- **Healthcare**: Predicting readmission, mortality, and stay length from the same patient data.

**Significance:**

MTL is more data-efficient and produces more robust models than single-task learning, especially when individual tasks have limited labeled data.

## **Q1. Define Directed Graphical Models (DGMs). Explain how Bayesian Networks represent joint probability distributions.**

<Highlight color="pink">**Directed Graphical Models (DGMs)** are probabilistic models that use a **directed graph** to show dependencies between random variables.</Highlight> Each **node** = a variable, each **arrow** = a dependency.

A **Bayesian Network** is a DGM whose graph is a **DAG (Directed Acyclic Graph)** — no cycles. Each variable has a **conditional probability table (CPT)** based on its parents.

**Joint Probability:**

The joint distribution is written as a product of conditional probabilities:
$$
P(X_1, X_2, \dots, X_n) = \prod_{i=1}^{n} P(X_i \mid \text{Parents}(X_i))
$$

**Example:**

<Mermaid chart={`graph LR
  A[Cloudy] --> B[Sprinkler]
  A --> C[Rain]
  B --> D[Wet Grass]
  C --> D
`} />

$$
P(A, B, C, D) = P(A) \cdot P(B \mid A) \cdot P(C \mid A) \cdot P(D \mid B, C)
$$

Instead of needing $2^4 - 1 = 15$ parameters for the full joint, this factorized form needs only **9** parameters.

**Significance:**

* **Compact:** Needs much fewer parameters than full joint table.
* **Efficient:** Makes probability calculations faster.
- **Interpretable**: The graph visually shows which variables depend on which.
- **Applications**: Medical diagnosis, spam filtering, fault detection.

## **Q2. Explain the concept of conditional independence in Directed Graphical Models with graphical intuition.**

**Conditional independence** means two variables don't affect each other once we know a third variable. Formally, $X$ and $Y$ are conditionally independent given $Z$ if:
$$
P(X, Y \mid Z) = P(X \mid Z)P(Y \mid Z)
$$
Written as: $X \perp Y \mid Z$.

In Bayesian Networks, the graph structure directly tells us which variables are conditionally independent. The rule: **a node is independent of all non-descendants given its parents** (local Markov property).

We use **d-separation** to check: if all paths between two nodes are "blocked" by observed variables, they are conditionally independent.

**Three basic structures:**

<div className="grid grid-cols-1 md:grid-cols-3 gap-8">

<div>

**Chain** — $A \perp C \mid B$

<Mermaid chart={`graph LR
  A --> B --> C
`} />

Observing B blocks the path.

</div>

<div>

**Fork** — $B \perp C \mid A$

<Mermaid chart={`graph LR
  A --> B
  A --> C
`} />

Observing the common cause A blocks the path.

</div>

<div>

**Collider** — $A \perp C$ (but **not** given B)

<Mermaid chart={`graph LR
  A --> B
  C --> B
`} />

Observing B *opens* the path (explaining away).

</div>

</div>

**Significance:**

- Reduces the number of parameters in the model.
- Makes inference algorithms faster.
- Tells us which variables actually influence each other.

## **Q3. Describe inference in Bayesian Networks. Why is exact inference difficult in large networks?**

**Inference** means computing the probability of some variables **given observed evidence**:
$$
P(X \mid E) = \frac{P(X, E)}{P(E)}
$$

**Exact Inference Methods:**

1. **Variable Elimination**: Removes hidden variables one by one by summing them out.
2. **Belief Propagation**: Passes messages between nodes to compute probabilities (works well on tree-shaped networks).

**Why is exact inference difficult in large networks?**

Exact inference is **NP-hard** in general because:
- The intermediate tables grow **exponentially** with the number of connected variables.
- This requires too much **time and memory** for large networks.

**Approximate Methods (used instead):**

- **Sampling** (e.g., Gibbs sampling): Draw random samples to estimate probabilities.
- **Variational Inference**: Approximate the true distribution with a simpler one.
- **Loopy Belief Propagation**: Apply message passing even on graphs with cycles (approximate but practical).

**Significance:**

Inference is what makes Bayesian Networks useful — it lets us predict outcomes, diagnose causes, and update our beliefs when new evidence arrives.

### **Q4. Explain parameter learning in Directed Graphical Models. Differentiate between MLE and Bayesian estimation.**

## Parameter Learning in Directed Graphical Models (DGM)

In a Directed Graphical Model (like Bayesian Network), the structure shows dependencies between variables.

**Parameter learning** means estimating the **conditional probability tables (CPTs)** from data.

If structure is known, we only estimate:

$$
P(X_i \mid Parents(X_i))
$$

Using training data.

---

## 1) Maximum Likelihood Estimation (MLE)

MLE estimates parameters by **maximizing likelihood of observed data**.

For discrete case:

$$
\theta = \frac{\text{count of (child, parent)}}{\text{count of parent}}
$$

It simply uses frequency from data.

**Features:**

* Uses only observed data.
* No prior knowledge.
* Simple and fast.
* Can give zero probability if event not seen.

---

## 2) Bayesian Estimation

Bayesian method combines:

* Prior belief (prior distribution)
* Observed data

Using Bayes rule:

$$
Posterior \propto Likelihood \times Prior
$$

Commonly uses **Dirichlet prior** for discrete variables.

**Features:**

* Avoids zero probabilities.
* Works well with small data.
* Incorporates prior knowledge.
* More computationally complex.

---

## Difference Between MLE and Bayesian

| MLE                       | Bayesian                    |
| ------------------------- | --------------------------- |
| Uses only data            | Uses prior + data           |
| No prior assumption       | Requires prior              |
| Can give zero probability | Avoids zero probability     |
| Simpler                   | More robust with small data |

### **Q5. What are Decision Diagrams? Explain their role and advantages.**

A **Decision Diagram** is a compact graph that represents **decision functions or probability tables** without redundancy. Internal nodes = decision/chance variables, leaf nodes = outcomes.

**Types:**

- **BDD (Binary Decision Diagram)**: Represents Boolean (True/False) functions.
- **ADD (Algebraic Decision Diagram)**: Handles real-valued functions; used to store CPTs in Bayesian Networks.
- **ODD (Ordered Decision Diagram)**: Variables follow a fixed order along every path.

**Role in Graphical Models:**

1. Store **conditional probability tables** compactly by merging identical sub-tables.
2. Speed up **inference** by doing operations (sum, product) directly on the diagram.
3. Represent **decision policies** in influence diagrams.

**Advantages:**

| Advantage | Why it matters |
|---|---|
| **Compact** | Shares repeated sub-structures, saves memory |
| **Faster** | Operations on diagrams are quicker than on flat tables |
| **Scalable** | Works where full tables would be too large |

**Example:** A CPT with 5 binary parents normally needs $2^5 = 32$ entries. If many entries are the same, a decision diagram stores it with far fewer nodes.

**Significance:**

Decision diagrams make it practical to work with large probabilistic models that would otherwise be too expensive to compute.

## **Q8. A sequence consists of 5 binary variables:**

- (a) Find the number of parameters required if modelled as a first-order Markov chain.
- (b) Find the number of parameters required if modelled as a DGM where each node has two parents.
</LongQuestion>
---

## **Answer:**

### **(a) First-order Markov chain**

Structure: $X_1 \rightarrow X_2 \rightarrow X_3 \rightarrow X_4 \rightarrow X_5$

**1. Initial Probability $P(X_1)$:**
- Number of parents ($m$) = 0
- Parent configurations $q = 2^m = 2^0 = 1$
- Binary variable requires $2 - 1 = 1$ independent parameter per configuration.
- **Parameters = $1 \times 1 = 1$**

**2. Transition Probabilities ($X_t \mid X_{t-1}$):**
- For each node $X_2$ to $X_5$, number of parents ($m$) = 1
- Parent configurations $q = 2^m = 2^1 = 2$
- Parameters per node = $q \times (2 - 1) = 2$
- For 4 transitions ($X_2, X_3, X_4, X_5$): $4 \times 2 = 8$ parameters.

**Total Parameters:**
$$
\text{Initial Probability} + (\text{Transitions} \times \text{Parameters per Transition})
$$
$$
1 + (4 \times 2) = 9
$$
$$
\boxed{9 \text{ parameters}}
$$

---

### **(b) Directed Graphical Model with two parents per node**

- Number of parents ($m$) = 2 for each node.
- Parent configurations $q = 2^m = 2^2 = 4$.
- Parameters per node = $q \times (2 - 1) = 4$.
- For 5 nodes:
$$
5 \times 4 = 20
$$

$$
\boxed{20 \text{ parameters}}
$$
