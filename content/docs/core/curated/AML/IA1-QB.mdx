## Q2. Describe the structure of a Generalized Linear Model (GLM).

A **Generalized Linear Model (GLM)** is an extension of linear regression that allows the response variable to follow distributions other than the normal distribution.

A GLM consists of three components:

1. **Random component**
   
   It specifies the probability distribution of the response variable, which must belong to the exponential family.

2. **Systematic component**
   
   It is the linear predictor given by:
   $$
   \eta = \beta_0 + \beta_1 x_1 + \cdots + \beta_p x_p = X\beta
   $$

3. **Link function**
   
   It connects the expected value of the response variable to the linear predictor:
   $$
   g(\mu) = \eta
   $$

Thus, GLMs allow flexible modeling of different types of data using linear predictors.

## Q4. Explain Probit regression and compare it conceptually with Logistic regression.

**Probit regression** is a statistical model used for binary classification problems where the response variable takes values 0 or 1. It models the probability of the positive class using the **cumulative distribution function (CDF) of the standard normal distribution**.

The probit model is expressed as:
$$
P(y=1|x) = \Phi(X\beta)
$$
where $\Phi(\cdot)$ denotes the standard normal CDF.

Probit regression assumes the existence of an underlying <Highlight color="blue">**latent variable**</Highlight> that follows a normal distribution. The observed binary outcome depends on whether this latent variable crosses a threshold.

**Comparison with Logistic Regression:**

**Logistic regression**, in contrast, uses the logistic (sigmoid) function to model probabilities and assumes a logistic distribution for the error term. Although the link functions differ, both models yield very similar probability estimates in practice.

## **Q1. Define Directed Graphical Models (DGMs). Explain how Bayesian Networks represent joint probability distributions.**

Directed Graphical Models (DGMs) are probabilistic models that represent random variables using a **directed graph**. Each node represents a random variable, and directed edges represent probabilistic dependencies between variables.

A **Bayesian Network** is a type of DGM whose graph is a **Directed Acyclic Graph (DAG)**. Each variable is associated with a conditional probability distribution given its parent variables.

A Bayesian Network represents the joint probability distribution as a product of conditional probabilities:
$$
P(X_1, X_2, \dots, X_n) = \prod_{i=1}^{n} P(X_i \mid \text{Parents}(X_i))
$$

This factorization reduces complexity and allows efficient probabilistic reasoning.

## **Q2. Explain the concept of conditional independence in Directed Graphical Models with graphical intuition.**

Conditional independence means that two variables are independent given knowledge of a third variable. Variables (X) and (Y) are conditionally independent given (Z) if:
$$
P(X, Y \mid Z) = P(X \mid Z)P(Y \mid Z)
$$

In Bayesian Networks, conditional independence is encoded by the graph structure. A node is conditionally independent of its non-descendants given its parents.

Graphically, conditional independence is determined using **d-separation**, which checks whether all paths between two variables are blocked given observed variables. If all paths are blocked, the variables are conditionally independent.

## **Q3. Describe inference in Bayesian Networks. Why is exact inference difficult in large networks?**

Inference in Bayesian Networks involves computing posterior probabilities of variables given observed evidence:
$$
P(X \mid E)
$$

Exact inference methods include variable elimination and belief propagation. These methods exploit the factorized structure of the network.

However, exact inference becomes computationally difficult in large networks because intermediate computations grow **exponentially** with the number of variables. This leads to high time and memory requirements.

Therefore, approximate inference methods such as sampling are often used in large Bayesian Networks.

## **Q4. Explain parameter learning in Directed Graphical Models. Differentiate between MLE and Bayesian estimation.**

Parameter learning in DGMs involves estimating the conditional probability distributions of each node using data, assuming the network structure is known.

In **Maximum Likelihood Estimation (MLE)**, parameters are chosen to maximize the likelihood of the observed data:
$$
\theta_{MLE} = \arg\max_\theta P(D \mid \theta)
$$
MLE relies only on data and does not use prior knowledge.

In **Bayesian estimation**, parameters are treated as random variables with prior distributions:
$$
P(\theta \mid D) \propto P(D \mid \theta)P(\theta)
$$
Bayesian estimation incorporates prior knowledge and helps reduce overfitting.

## **Q5. What are Decision Diagrams? Explain their role and advantages.**

Decision Diagrams are graph-based representations used to model decisions and probabilistic outcomes in a compact form. They represent decision variables, chance variables, and outcomes using directed graphs.

In probabilistic graphical models, decision diagrams are used to efficiently represent conditional probability tables and decision policies. They reduce redundancy by sharing common substructures.

Their advantages include reduced memory usage, faster inference, and better scalability, making them useful in decision-making systems and probabilistic modeling.
