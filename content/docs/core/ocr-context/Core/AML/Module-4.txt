# Introduction to Sequential Probabilistic Models

## What to Model?

- Many real-world problems involve sequences (speech, text, stock prices, biological signals).
- We model these using probabilistic chains that capture how current events depend on past events.

## Two Core Models:

- Markov Models:
- The current state depends only on the previous one.
- Hidden Markov Models (HMMs):
- Similar to Markov models, but the state is not directly visible; only outputs generated by hidden states are seen.

# Markov Models

## Basic Idea:

- A Markov chain is a sequence of random variables in which each state depends only on the previous one (the Markov property).
- Used when the system is fully observable.

## Transition Probabilities:

- Each state has probabilities of transitioning to others.
- Example: Today's weather depends only on yesterday's weather.

## Uses:

- Modeling physical systems, board games (e.g., snakes and ladders), page transitions on websites, etc.

# Examples

- Application:
- Ranking search results.

# Hidden Markov Models

## Structure:
- Two-layer model: 1) A Markov chain of hidden states. 2) Each hidden state emits an observable output.

## Key Parameters:
- Initial state distribution.
- Transition probabilities between hidden states.
- Emission probabilities for observations given hidden states.

## Why Use HMMs?
- To model uncertainty in system states.
- To allow inference of hidden causes from observable data.
- To handle noisy or incomplete sequences

# Inference in HMMs

- Question: Given the observed data, what can be inferred?
- Three Major Inference Tasks:

- A. Evaluation:
- Compute the likelihood of an observation sequence under a model.
- Tool: Forward Algorithm (efficient dynamic programming).

- B. Decoding:
- Find the most likely sequence of hidden states (the best explanation for the data).
- Tool: Viterbi Algorithm, similar in spirit to Dijkstra's algorithm for sequences.

- C. Posterior State Probabilities:
- Compute the probability of being in each state at each time step.
- Tool: Forward-Backward Algorithm (yields soft classification and

# Learning in HMMs

- **Goal:**
Estimate the model parameters (transition, emission, and initial state probabilities) from observed data alone.

- **Challenge:**
The hidden state sequences are not observed, so direct counting of transitions or emissions is impossible.

- **Solution:**
Use the Expectation-Maximization (EM) algorithm, specifically the Baum-Welch algorithm:
- **E-Step:** Estimate expected counts of transitions and emissions using the Forward-Backward algorithm.
- **M-Step:** Re-estimate parameters to maximize the expected likelihood.
- **Iteration:** Repeat until convergence (e.g., when the change in log-likelihood drops below a threshold).

- **Applications:** Used extensively in speech recognition, bioinformatics, handwriting recognition, etc.

# Motivation to use Markov Models

## Traditional Assumption:
- Machine learning often assumes instances are i.i.d. (independent and identically distributed).

## Reality with Sequential Data:
- Data like speech, DNA sequences, handwriting, and financial time series are dependent over time.

## Solution:
- Use Markov Models—and more generally, Hidden Markov Models (HMMs)—to handle temporal dependencies

# Markov Process

- Idea: A stochastic process where the future state depends only on the present state.
- Known as: The first-order Markov assumption.
- Key Equation: $P(q_{t+1} / q_t, q_{t-1}, \ldots, q_1) = P(q_{t+1} / q_t)$
- This simplifies dependency structure, making inference and learning more tractable.

# Observable Markov Models

## System Characteristics:
- States: $S_1, S_2, \ldots, S_N$
- At each time step $t$, the system is in a visible state, $q_t$.

## Model Components:
### Initial State Distribution:
- $\pi_i = P(q_1 = S_i)$
- Transition Probability Matrix:
- $a_{ij} = P(q_{t+1} = S_j \mid q_t = S_i)$
- Each row satisfies: $\sum_{j=1}^{N} a_{ij} = 1$

## Sequence Probability:
- For state sequence $Q = \{q_1, q_2, \ldots, q_T\}$:
- $P(Q \mid \Pi, A) = \pi_{q_1} \cdot a_{q_1q_2} \cdot a_{q_2q_3} \ldots a_{qT-1qT}$

Find the probability of the sequence:

$$
A \to B \to A \to B
$$

# Hidden Markov Models (HMMs)

## Real-World Scenario:
- States are hidden (latent) and cannot be observed directly.

## Observation:
- Instead, we observe outputs (emissions) that are probabilistically linked to the hidden states.

# HMM Structure

- Hidden States:
- $q_t \in \{S_1, \dots, S_N\}$
- Observable Outputs:
- $O_t \in \{v_1, \dots, v_M\}$
- Model Components:
- Initial State Probability: $\pi_i = P(q_1 = S_i)$
- Transition Probabilities: $a_{ij} = P(q_{t+1} = S_j \mid q_t = S_i)$
- Emission Probabilities: $b_j(m) = P(O_t = v_m \mid q_t = S_j)$
- Full Model Notation: $\lambda = (A, B, \Pi)$

# Generation Process in HMMs

- Step 1:
- Draw initial state $q_1 \sim \Pi$
- Step 2 (For Each Time t):
- Transition:
- $q_{t+1} \sim P(q_{t+1} \mid q_t)$
- Emission:
- $O_t \sim P(O_t \mid q_t)$

# Example - Urn and Ball Model

## Analogy:
- Urns: Represent hidden states (behind a curtain)
- Balls: Colored balls represent the observations

## Comparison:
- Observable Markov Models: Both urn (state) and ball (observation) are visible.
- HMMs: Only the ball (observation) is visible; the urn (hidden state) remains unknown.

# Graphical Model Representation

## Dynamic Bayesian Network:
- Hidden Layer (States): $q_1 \rightarrow q_2 \rightarrow \ldots \rightarrow q_T$
- Observed Layer: Each state $q_t$ generates an observation $O_t$

## Captures:
- Markov dependency over time
- Conditional independence of observations given the states

# Markov Model

- A Markov model (or Discrete-Time Markov Chain) describes a stochastic process where the system transitions between discrete states over time.
- Key Idea:
The next state depends solely on the current state—not on the entire past—signifying the Markov property (memorylessness).

# First-Order Markov Property

- Property Equation:
$$
P(q_{t+1} \mid q_t, q_{t-1}, \dots, q_1) = P(q_{t+1} \mid q_t)
$$

- Advantage:
- Eliminates long-range temporal dependencies, simplifying analysis and learning.

# Components of a Markov Model

- State Space $S = \{S_1, S_2, \ldots, S_N\}$:
- The system occupies one of these discrete states at any time $t$ (for $t = 1, 2, \ldots, T$).

- Initial State Distribution $\Pi$:
- $\pi_i = P(q_1 = S_i)$ with $\sum_{i=1}^{N} \pi_i = 1$

- Transition Probability Matrix $A$:
- $a_{ij} = P(q_{t+1} = S_j \mid q_t = S_i)$ with $\sum_{j=1}^{N} a_{ij} = 1$ (row-stochastic)

# Diagram representation has these components

- Visualization as a Graph (Stochastic Automaton):
- Nodes: Represent states $S_i$.
- Edges: Represent transitions with probabilities $a_{ij}$.

- Process:
The model starts in a state (per $\Pi$) and randomly transitions between states according to $A$.

# Example - 3-State Markov Model

## States (Colors):

- $S_1 = \text{Red}$
- $S_2 = \text{Blue}$
- $S_3 = \text{Green}$

## Parameters:

- **Initial Distribution**: $\Pi = [0.5, 0.2, 0.3]$
- **Transition Matrix**:
- For Red: [0.4, 0.3, 0.3]
- For Blue: [0.2, 0.6, 0.2]
- For Green: [0.1, 0.1, 0.8]

## Observed Sequence:

$Q = \{S_1, S_1, S_3, S_3\}$

## Sequence Probability:

(Multiply the initial probability with the transitions.)

- $P(Q) = \pi_{S_1} \cdot a_{11} \cdot a_{13} \cdot a_{33} = 0.5 \times 0.4 \times 0.3 \times 0.8 = 0.048$

# Estimating Parameters from Data

- Initial Probability Estimate:
$$
\sigma \hat{\pi}_i = \frac{\# \text{ sequences starting with } S_i}{K}
$$
where $K$ is the total number of sequences.

- Transition Probability Estimate:
$$
\sigma \hat{a}_{ij} = \frac{\# \text{ transitions from } S_i \text{ to } S_j}{\# \text{ transitions from } S_i}
$$

- Note:
These are maximum likelihood estimates assuming stationarity (homogeneity over time)

# Special Types of Markov Models

- **Homogeneous Markov Model:**
- $\diamondsuit$ Transition probabilities remain constant over time: $P(q_{t+1} \mid q_t) = a_{ij} \forall t$
- **Ergodic (Fully Connected) Model:**
- $\diamondsuit$ Every state is reachable from every other: $a_{ij} &gt; 0 \forall i,j$
- **Left-to-Right Model:** (Common in speech recognition)
- $\diamondsuit$ Transitions are forward only or self-transitions: $a_{ij} = 0$ for $j &lt; i$

# Second-Order Markov Model

- **Definition:**
The next state depends on the last two states: $P(q_{t+1} = S_k \mid q_t = S_j, q_{t-1} = S_i) = a_{ijk}$

- **Pros and Cons:**
More expressive than a first-order model but requires $O(N^3)$ parameters, thus more data.

- **Conversion idea towards first order:**
Can be converted to a first-order model by defining new states as ordered pairs: $(q_{t-1}, q_t)$.

# Applications

- **Suitable When:**
- States are observable.
- The system exhibits memoryless transitions.

- **Common Uses:**
- Robot localization
- Board game modeling
- Simplified weather forecasting
- Basic biological process modeling

# Overall key ideas

## Components:
- State Space S: Set of possible states
- Initial Probabilities Π: Probability distribution over starting states
- Transition Matrix A: Probabilities of moving between states

## Assumptions:
- First-order, time-homogeneous, and discrete states.

## Sequence Probability:
- Computed as the product of the initial probability and the transition probabilities.

## Estimation:
- Derived via count-based maximum likelihood from observed sequences.

## Key Variants:
- Emodia, left-to-right, and higher-order models

# Need for HMM

## Challenge in Real-World Data:

- In many cases, the true state of a system is not directly observable.
- Instead of observing states, we only see outputs that are probabilistically linked to hidden states.

## The HMM Advantage:

- Introduces a two-layer structure:
- Hidden State Sequence: $Q = \{q_1, q_2, \dots, q_T\}$
- Observable Output Sequence: $O = \{O_1, O_2, \dots, O_T\}$
- Helpful in applications (speech, handwriting, genomics) where underlying process is latent.

# Components of an HMM

- Parameter Set: $\lambda = (A,B,\Pi)$

- States (S)
- $S = \{S_1,S_2,\dots,S_N\}$
- Each hidden state $q_{t} \in S$; these are not directly observable.

- Observations (V)
- $V = \{v_{1},v_{2},\ldots ,v_{M}\}$
- Each observable output $O_{t} \in V$ is a measurable symbol.

- Initial State Distribution (Π)
- $\pi_{i} = P(q_{1} = S_{i})$ with $\sum_{i=1}^{N} \pi_{i} = 1$

- State Transition Probabilities (A):
- $a_{ij} = P(q_{t + 1} = S_j \mid q_t = S_i)$
- Every row of $A$ sums to 1.

- Emission Probabilities (B):
- $b_{j}(m) = P(O_{t} = v_{m} \mid q_{t} = S_{j})$
- For each state $S_{j}$, $\sum_{m=1}^{M} b_{j}(m) = 1$.

# HMM Generation Process

## Sequence Generation Procedure:

### Initialize:
- Sample the initial state: $q_1 \sim \Pi$.

### For each time step $t = 1$ to $T$:
- Emission: Produce observation $O_t$ by sampling from the distribution $P(O_t \mid q_t) = b_{q_t}(O_t)$.
- Transition: Transition to the next state by sampling $q_{t+1} \sim P(q_{t+1} \mid q_t) = a_{q_t q_{t+1}}$.

## Overall Effect:

The overall observed sequence $O$ is generated indirectly through the latent state sequence $Q$ combined with the

# Joint Probability of Observations and States

## Mathematical Expression:
For a specific state sequence $Q = \{q_1, q_2, \ldots, q_T\}$ and an observation sequence $O = \{O_1, O_2, \ldots, O_T\}$:
$$
P(O, Q \mid \lambda) = \pi_{q_1} \cdot \prod_{t=2}^{T} a_{q_{t-1}q_t} \cdot \prod_{t=1}^{T} b_{q_t}(O_t)
$$

## Explanation:
Multiply the initial state probability $\pi_{q_1}$ by all state transition probabilities along $Q$ and by the emission probabilities for every observation in $O$.

# Urn and Ball Analogy

## Analogy Details:

- Urns Represent Hidden States:
- Each urn corresponds to a hidden state $S_{i}$.

- Balls Represent Observations:
- The colored balls drawn correspond to observable symbols $v_{m}$.

## Process Breakdown:

- While one can see only the color of the ball (the observation), it can't be known from which urn (hidden state) it came from.

- State transitions (switching urns) are governed by $A$, and each urn has a unique emission probability distribution described by $B$.

# What does "Hidden" mean

## Differences:

- Observable Markov Models:
- The entire state sequence $Q$ is visible.

- Hidden Markov Models:
- Only the observation sequence $O$ is directly visible; the state sequence $Q$ remains concealed.

## It means that:

- Learning or inferring $Q$ from $O$ is non-trivial, requiring dedicated algorithms.

## Weather Analogy:

- Hidden Aspect: Actual weather (sunny/rainy) is not seen.
- Observable Aspect: Clothing choices (sunglasses, umbrellas) act as noisy indicators of the weather.

# Observed Sequence vs. Hidden Sequence

## Observation Dynamics:

- Observed Sequence $O$:
- Directly available as $\{O_1, O_2, \dots, O_T\}$.
- Hidden Sequence $Q$:
- Governs the generation of $O$ but is not directly observed.

## Mathematical Implication:

- To obtain the overall likelihood of observations, you must marginalize: $P(O \mid \lambda) = \sum_{Q} P(O, Q \mid \lambda)$
- This summation over all possible hidden sequences $Q$ is computationally challenging.

# Graphical Model View &amp; DBN Structure

## Graphical Representation of an HMM:

### Dynamic Bayesian Network (DBN):
- Hidden State Chain: $q_1 \rightarrow q_2 \rightarrow \dots \rightarrow q_T$
- Emission Links: Each $q_t$ produces $O_t$ (represented by an arrow from $q_t$ to $O_t$).

## Conditional Independence in the Model:

### Markov Property:
- $P(q_t \mid q_{t-1}, q_{t-2}, \ldots) = P(q_t \mid q_{t-1})$

### Emission Independence:
- $P(O_t \mid q_t, q_{t-1}, O_{t-1}, \ldots) = P(O_t \mid q_t)$

## Advantage:

- This structure simplifies the joint probability distribution and makes efficient inference (using Forward-Backward and Viterbi algorithms) possible.

# Probabilistic Interpretation

- **Transition Probabilities (A):**
- $a_{ij} = P(q_{t+1} = S_j \mid q_t = S_i)$
- **Properties:**
- $a_{ij} \geq 0$ and for each $S_i, \sum_{j=1}^{N} a_{ij} = 1$.

- **Emission Probabilities (B):**
- $b_j(m) = P(O_t = v_m \mid q_t = S_j)$
- **Properties:**
- $b_j(m) \geq 0$ and for each $S_j, \sum_{m=1}^{M} b_j(m) = 1$.

- **Initial Probabilities (Π):**
- $\pi_i = P(q_1 = S_i)$ with $\sum_{i=1}^{N} \pi_i = 1$.

- **Complete Model:**
- Together, these define the full parameter set $\lambda = (A,B,\Pi)$, which guides the generative process:
- Choose initial state $q_1 \sim \Pi$.
- For each $t$: Emit $O_t$ and transition to $q_{t+1}$.

# Issues Involving Inference (Very Important)

When given only an observed sequence $O = \{O_1, O_2, \dots, O_T\}$, there are three fundamental questions:

- **A) Evaluation:**
- **Question:** What is the probability $P(O \mid \lambda)$ that the observed sequence was generated by the model?
- **Answer:**
- Since the states $Q$ are hidden, the likelihood is computed by summing over all possible state sequences: $P(O \mid \lambda) = \sum_{Q} P(O, Q \mid \lambda)$
- **Algorithm:** The Forward algorithm uses dynamic programming to efficiently perform this summation, avoiding an exponential number of calculations.

# Issues Involving Inference...(Very Important)

## B) Decoding:

- **Question**: What is the most likely hidden state sequence $Q^*$ that explains the observed data?
- **Answer**:
- Identify the path $Q^*$ that maximizes $P(Q \mid O, \lambda)$.
- **Algorithm**: The Viterbi algorithm finds this optimal sequence using a recursive maximization strategy that exploits the Markov property.

## C) Learning:

- **Question**: How do we estimate the model parameters $\lambda = (A,B,\Pi)$ from the data?
- **Answer**:
- Since the states are hidden, parameters are not directly observable.
- **Algorithm**: The Baum-Welch algorithm (a form of Expectation-Maximization or EM) iteratively adjusts $\lambda$ to maximize $P(O \mid \lambda)$ by computing expected counts for transitions and emissions, then re-estimating parameter

# Issues Involving Inference...(Very Important)

## These Tasks Are Challenging:

- Because the hidden state sequence is not known, a direct computation of probabilities is infeasible.
- The computational challenge is managed by dynamic programming methods, which break the problem into recursive subproblems (e.g., Forward-Backward for evaluation, Viterbi for decoding).

$$

# Overall key things to learn

- **Core Components of an HMM:**
- Hidden States $S$ and Observations $V$
- Parameters: Transition Matrix $A$, Emission Matrix $B$, and Initial Distribution $\Pi$
- Full Generative Model: $\lambda = (A,B,\Pi)$

- **Inference Objectives:**
- Evaluation: Use the Forward algorithm to compute $P(O \mid \lambda)$.
- Decoding: Use the Viterbi algorithm to infer the most probable hidden state sequence $Q^*$.
- Learning: Apply the Baum-Welch (EM) algorithm to estimate optimal parameters from observed data.

- **Applications:**
- Speech recognition, part-of-speech tagging, bioinformatics, handwriting recognition, etc.

# "Inference" in HMMs

## HMM :

- An HMM generates an observation sequence $O = \{O_1, O_2, \dots, O_T\}$ from a hidden state sequence $Q = \{q_1, q_2, \dots, q_T\}$.
- The states $Q$ are not directly observed.

## Inference Goals:

- **Evaluation**: Compute the likelihood $P(O \mid \lambda)$ under the model $\lambda = (A, B, \Pi)$.
- **Decoding**: Determine the most probable sequence of hidden states.
- **State Marginals**: Compute $P(q_{t} = S_{i} \mid O, \lambda)$ for each time step $t$.

## Issue:

Because there are $N^T$ possible state sequences, dynamic programming algorithms are required for efficient computation.

# Evaluation Problem - Naive Method

## Objective:
- Compute the total likelihood of the observation sequence: $P(O \mid \lambda) = \sum_{Q} P(O, Q \mid \lambda)$

## Naive Approach (Inefficient):
- Sum over all $N^T$ hidden state sequences—computationally infeasible for large $T$.

## Main Issue here:
- A higher $P(O \mid \lambda)$ indicates a better model fit.
- Essential for model comparison and the Expectation (E) step in Baum-Welch algorithm training.

# Evaluation Problem - The Forward Algorithm

## Idea:

- Efficiently compute $P(O \mid \lambda)$ without enumerating all state sequences.

## Forward Variable $\alpha_{t}(i)$: $\alpha_{t}(i) = P(O_{1},O_{2},\dots,O_{t},q_{t} = S_{i}\mid \lambda)$

- Represents the probability of observing the first $t$ symbols and ending in state $S_{i}$ at time $t$.

## Algorithm Steps:

- Initialization (t = 1): $\alpha_{1}(i) = \pi_{i} \cdot b_{i}(O_{1})$
- Recursion (t = 2 to T): $\alpha_{t}(j) = \sum_{i=1}^{N} \alpha_{t-1}(i) \cdot a_{ij} \cdot b_{j}(O_{t})$
- Termination: $P(O \mid \lambda) = \sum_{i=1}^{N} \alpha_{T}(i)$

## Time Complexity: $O(N^{2} \cdot T)$

# Decoding - Finding the Best Hidden Sequence

## Objective:
- Identify the most probable hidden state sequence:
$$
Q^* = \arg\max_{Q} P(Q \mathcal{O}, \lambda) = \arg\max_{Q} P(O, Q \mid \lambda)
$$

## Viterbi Algorithm:
### Viterbi Variable $\delta_t(i)$:
$$
\delta_t(i) = \max_{q_1, \dots, q_{t-1}} P(q_1, \dots, q_{t-1}, q_t = S_i, O_1, \dots, O_t \mid \lambda)
$$

### Backpointers $\psi_t(i)$:
$$
\psi_t(i) = \arg\max_{j} [\delta_{t-1}(j) \cdot a_{ji}]
$$

- Records the best previous state that led to $S_i$ at time $t$.

# Decoding - Finding the Best Hidden Sequence..

## Viterbi Steps:

- Initialization (t = 1):
- $\delta_1(i) = \pi_i \cdot b_i(O_1)$
- $\psi_1(i) = 0$
- Recursion (t = 2 to T):
- $\delta_t(j) = \left[ \max_{i} \delta_{t-1}(i) \cdot a_{ij} \right] \cdot b_j(O_t)$
- $\psi_t(j) = \arg\max_{i} \left[ \delta_{t-1}(i) \cdot a_{ij} \right]$
- Termination: $q_T^* = \arg \max_{i} \delta_T(i)$
- Backtrace (t = T-1 to 1): $q_t^* = \psi_{t+1}(q_{t+1}^*)$
- Time Complexity: $O(N^2 \cdot T)$

# The Learning Problem

## Challenge:

- Learn the parameters $\lambda = (A,B,\Pi)$ from one or more observed sequences $O^{(1)},O^{(2)},\ldots ,O^{(K)}$.
- Given: Only observation sequences $O = \{O_1,O_2,\dots,O_T\}$.
- Missing: The labels for the hidden state sequences $Q = \{q_{1}, q_{2}, \ldots, q_{T}\}$.

## Why It's Central:

- Without the hidden state sequence, direct counting of transitions (from $S_{i}$ to $S_{j}$) or emissions (from state $S_{j}$ to symbol $v_{k}$) is not possible.

## Goal:

- Estimate the HMM parameters:
- Transition Matrix $A = [a_{ij}]$
- Emission Matrix $B = [b_{j}(k)]$
- Initial Distribution $\Pi = [\pi_{i}]$

# Direct Maximum Likelihood Estimation (MLE) Fails

- Direct MLE (if $Q$ were known):
- Count state transitions: $S_i \rightarrow S_j$
- Count emissions: from $S_j$ to $v_k$

- Problem:
- Since $Q$ is hidden, we cannot directly count these events.
- Solution: Use expected counts instead of raw counts.

- A possible approach:
- Employ the Expectation-Maximization (EM) algorithm, specifically the Baum-Welch algorithm, to iteratively estimate expected counts and update parameters.

# EM (Baum-Welch) Algorithm

## EM Algorithm:
- An iterative two-step process used to find maximum likelihood estimates when latent variables (hidden states) exist.

## Two Main Steps:
- **E-Step (Expectation):**
Compute the expectations of the latent variables (hidden states) given the current model.
- **M-Step (Maximization):**
Update (maximize) the expected complete-data likelihood by re-estimating the model parameters $A, B$, and $\Pi$.

## In HMMs:
- **E-Step:** Use the Forward-Backward algorithm to compute:
- Forward probabilities $\alpha_t(i)$
- Backward probabilities $\beta_t(i)$
- Posterior state probabilities $\gamma_t(i)$
- Transition probabilities $\xi_t(i,j)$
- **M-Step:** Re-estimate parameters using these expected counts.

# Baum-Welch Algorithm - The E-Step

This is to Compute expected counts using dynamic programming.

Forward Probability $\alpha_{t}(i)$:

$$
\begin{array}{l}
\Rightarrow \alpha_{t}(i) = P(O_{1}, O_{2}, \dots, O_{t}, q_{t} = S_{i} \mid \lambda) \\
\Rightarrow \text{"What is the probability of seeing the first } t \text{ observations and} \\
\text{being in state } S_{i}?\text{"}
\end{array}
$$

Backward Probability $\beta_{t}(i)$:

$$
\begin{array}{l}
\Rightarrow \beta_{t}(i) = P(O_{t+1}, O_{t+2}, \dots, O_{T} \mid q_{t} = S_{i}, \lambda) \\
\Rightarrow \text{"What is the probability of observing the remaining sequence from} \\
\text{state } S_{i}?"
\end{array}
$$

# Baum-Welch Algorithm - The E-Step..

Posterior State Probability $\gamma_t(i)$:

$$
\gamma_t(i) = P(q_t = S_i \mid O, \lambda) = \frac{\alpha_t(i) \cdot \beta_t(i)}{P(O \mid \lambda)}
$$

Used for updating:

- Initial state counts
- Emission counts (state visitation)

Transition Probability $\xi_t(i,j)$:

$$
\xi_t(i, j) = P(q_t = S_i, q_{t+1} = S_j \mid O, \lambda) = \frac{\alpha_t(i) \cdot a_{ij} \cdot b_j(O_{t+1}) \cdot \beta_{t+1}(j)}{P(O \mid \lambda)}
$$

Used for updating:

- Transition counts from state $i$ to state $j$

# Baum-Welch Algorithm - The M-Step

This is to Re-estimate model parameters using the expected counts computed in the E-Step.

## Initial Distribution $\Pi$:

$\hat{\pi}_i = \gamma_1(i)$ (Probability that the first state is $S_i$)

## Transition Matrix $A$:

$$
\hat{a}_{ij} = \frac{\sum_{t=1}^{T-1} \xi_t(i,j)}{\sum_{t=1}^{T-1} \gamma_t(i)}
$$

- Numerator: Expected number of transitions from $S_i$ to $S_j$.
- Denominator: Expected number of times being in state $S_i$.

# Baum-Welch Algorithm - The M-Step..

- **Emission Matrix** $B$:

- $\hat{b}_j(k) = \frac{\sum_{t=1}^{T} \mathbb{1}(O_t = v_k) \cdot \gamma_t(j)}{\sum_{t=1}^{T} \gamma_t(j)}$

- Numerator: Expected number of times state $S_j$ emitted symbol $v_k$.
- Denominator: Total expected visits to state $S_j$.

- **Continuous Emissions (As a side point take note of this):**

- If emissions are continuous (e.g., modeled by Gaussians), estimate the mean and covariance using weighted statistics.

# Iterating Until Convergence

## Initialization:
- Start with random or heuristic initial values for $A, B$, and $\Pi$.

## Iterative Process:
- **E-Step:**
- Compute $\alpha, \beta, \gamma$, and $\xi$ using the current model.
- **M-Step:**
- Update $A, B$, and $\Pi$ using the formulas provided.
- **Likelihood Check:**
- Compute $P(O \mid \lambda)$ and compare the change in log-likelihood to a threshold.

## Convergence Guarantee:
- The log-likelihood will not decrease during training; the EM algorithm guarantees non-decreasing convergence.

# Key points to note

## Learning means:
- Find the maximum likelihood estimates of $\lambda = (A,B,\Pi)$ given only the observed sequences.

## Key Ideas:
- Hidden States Issue:
- Direct counting is impossible; we compute expected counts.
- EM (Baum-Welch):
- E-Step: Compute forward/backward variables to get $\gamma$ and $\xi$.
- M-Step: Re-estimate parameters using these expected counts.

## All this is meant for:
- Allows effective training of HMMs from unlabeled (hidden) data.
- Widely used in applications such as speech recognition, bioinformatics, and sequence analysis.

# Key points to note...

- Learning in HMMs hinges on using expected counts because direct counts are unavailable.
- The iterative Baum-Welch algorithm is a practical application of EM that ensures convergence by increasing the likelihood with each iteration.
- The process is foundational for training models on sequential data where hidden state labels are unknown.
- Applications: Speech recognition, Part-of-speech tagging, Bioinformatics (gene prediction), Handwriting recognition

# Generalization in HMMs

## Standard HMM Limitations:

- Hidden States:
- Follow a first-order Markov chain
- Limited memory: only the current state influences the next
- Observations:
- Discrete observations (cannot model continuous or complex data)
- State Durations:
- Implicitly geometric (memoryless assumptions lead to unrealistic temporal patterns)

So the idea is to overcome these limitations with extended models that better capture real-world

# Overview of HMM Generalizations

- Hidden Semi-Markov Models (HSMMs)
- Gaussian and Gaussian Mixture HMMs (GMM-HMMs)
- Input-Output HMMs (IOHMMs)
- Factorial HMMs (FHMMs)
- Coupled HMMs (CHMMs)
- Switching Linear Dynamical Systems (SLDS) or HMM + Kalman

# Hidden Semi-Markov Models (HSMMs)

Standard HMMs imply geometrically distributed state durations:

$$
P(d = k \mid q_t = i) = (a_{ii})^{k-1}(1 - a_{ii})
$$

This is unrealistic for many processes (e.g., structured speech segments).

## HSMM :

- Explicit Duration Modeling:
- Introduce a duration distribution $P_d(i,d)$ for each state $i$.
- Components:
- State Sequence: $q_1, \ldots, q_T$
- State Durations: $d_1, d_2, \ldots$ such that $\sum d_k = T$
- Emission Model: $P(O_t:O_{t+d-1} \mid q_t = i) = \prod_{k=0}^{d-1} P(O_{t+k} \mid q_t = i)$

## Murphy's Construction (From Kevin Murphy's book):

- Uses a semi-Markov graphical model where transitions depend on the elapsed time.
- Forward Message Example:

$$
\alpha_t(i) = \sum_{d=1}^{D_{\max}} \sum_j \alpha_{t-d}(j) a_{ji} P_d(i,d) \prod_{k=0}^{d-1} b_i(O_{t-k})
$$

# Gaussian and Gaussian Mixture HMMs (GMM-HMMs)

- Standard HMMs assume discrete emissions over a vocabulary $V$.
- Many observations are continuous-valued $(O_t \in \mathbb{R}^D)$.

## Emission Models:

- Gaussian HMM: $P(O_t \mid q_t = S_i) = N(O_t; \mu_i, \Sigma_i)$
- GMM-HMM: $P(O_t \mid q_t = S_i) = \sum_{m=1}^{M} c_{im} N(O_t; \mu_{im}, \Sigma_{im})$
- $c_{im}$ are mixture weights with $\sum_{m} c_{im} = 1$.

## Learning Enhancements:

- Use the EM algorithm with additional responsibilities $\gamma_{t,i,m}$, where:

$$
\mu_{im} \leftarrow \frac{\sum_{t} \gamma_{t,i,m} O_t}{\sum_{m} \mu_{im}}, \quad \Sigma_{im} \leftarrow \frac{\sum_{t} \gamma_{t,i,m} (O_{t} - \mu_{im}) (O_{t} - \mu_{im})^{\top}}{\sum_{m} \mu_{im}}
$$

# Input-Output HMMs (IOHMMs)

- Incorporate external inputs $x_t \in \mathbb{R}^d$ to influence the state transitions and emissions.
- Key forms:
- Transitions: $P(q_{t+1} = j \mid q_t = i, x_t) = \frac{\exp(w_{ij}^{\top}x_t)}{\sum_j \exp(w_{ij}^{\top}x_t)}$
- Emissions (e.g., regression): $O_t \mid q_t = j, x_t \sim N(W_j^{\top}x_t, \Sigma_j)$
- $W_j$: Regression coefficients for state $j$.
- $w_{ij}$: Logistic regression weights for transitions.
- IOHMMs share similarities with conditional random fields (CRFs) when the joint probability is not modeled.

# Factorial HMMs (FHMMs)

- Standard HMMs use one hidden state per time step. In many systems, multiple independent latent factors evolve concurrently and jointly influence the observation.

## Model:

- Hidden State Representation: $q_{t} = (q_{t}^{(1)}, q_{t}^{(2)}, \dots, q_{t}^{(M)})$
- Independence Assumption: $P(q_{t} \mid q_{t-1}) = \prod_{m=1}^{M} P(q_{t}^{(m)} \mid q_{t-1}^{(m)})$
- Observation Model: $O_{t} \sim P\left(O_{t} \mid q_{t}^{(1)}, \dots, q_{t}^{(M)}\right)$

- Gaussian Example: $O_{t} = \sum_{m=1}^{M} W^{(m)} q_{t}^{(m)} + \epsilon_{t}, \epsilon_{t} \sim N(0, \Sigma)$

- Challenge here is:
- The total hidden state space grows as $N^M$; structured variational methods or mean-field approximations are used.

# Coupled HMMs (CHMMs)

Model multiple interacting sequences (e.g., in multi-person tracking) where chains can influence each other.

## Model :

- Multiple Chains:
- Let there be $C$ chains with hidden states $q_{t}^{(c)}$ for $c = 1, \ldots, C$.
- Transition Coupling: $P\left(q_{t}^{(1)}, \ldots, q_{t}^{(C)} \mid q_{t-1}^{(1)}, \ldots, q_{t-1}^{(C)}\right) = \prod_{c=1}^{C} P\left(q_{t}^{(c)} \mid q_{t-1}^{(1)}, \ldots, q_{t-1}^{(C)}\right)$
- Emission Model:
- Each chain emits its own observation: $P(O_{t}^{(c)} \mid q_{t}^{(c)})$.

# Applicability of Generalizations

- **HSMM:**
- When explicit state durations are needed.

- **Gaussian/GMM-HMM:**
- When observations are real-valued.

- **IOHMM:**
- When external inputs influence state transitions or emissions.

- **Factorial HMM:**
- When multiple independent latent factors jointly generate data.

- **Coupled HMM:**
- When modeling interacting processes or multiple agents.

Each generalization is a mathematical innovation to address specific HMM limitations.

They extend the standard HMM framework to capture more complex phenomena.
