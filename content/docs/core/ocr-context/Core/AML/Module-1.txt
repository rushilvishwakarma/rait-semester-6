# Quick Recap: Random Variables

- A random variable is a function that assigns a numerical value to each possible outcome of a random experiment.
- Instead of working with outcomes like heads/tails or rain/no rain, a random variable converts these outcomes into numbers, making them easier to analyze mathematically.
- Example
- $\triangle$ Outcome: Head → X=1
- $\triangle$ Outcome: Tail → X=0

# Types of Random Variables

- Discrete Random Variable
- Takes countable values
- Example: Number of students present in a class
- Continuous Random Variable
- Takes any value in a range
- Example: Height, weight, time
- A random variable maps outcomes of randomness to numbers so we can apply probability and statistical analysis.

# Quick Recap: Probability Density Function (PDF)

- A Probability Density Function (PDF) describes how probability is distributed over the values of a continuous random variable.
- It does not give probability directly at a point.
- Probability is obtained by integration over an interval.
- For a continuous random variable $X$, a function $f(x)$ is a PDF if:
- Non-negativity
- $f(x) \geq 0 \ \forall x$
- Total probability is 1
- $\int_{-\infty}^{\infty} f(x) \, dx = 1$
- Probability over an interval
- $P(a \leq X \leq b) = \int_{a}^{b} f(x) \, dx$

# Key Properties of PDF

- $P(X=x)=0$ for continuous variables
- Probability is always found over ranges
- Area under the curve = probability
- PDF values may be greater than 1, but total area must be 1.

- Normal (Gaussian) Distribution
- $f(x) = \frac{1}{\sqrt{2\pi\sigma^2}}\exp \left(-\frac{\left(x - \mu\right)^2}{2\sigma^2}\right)$
- Bell-shaped curve
- Mean = Median = Mode = $\mu$
- Used widely in statistics and ML
- standard deviation ($\sigma$), width
- $\sigma^2$ is Variance

# Other PDFs

- Uniform Distribution
- Exponential Distribution
- Gamma Distribution
- Beta Distribution

# Probability Mass Functions (PMF)

- A Probability Mass Function (PMF) describes the probability distribution of a discrete random variable.
- It assigns a probability to each possible value of the random variable.
- For a discrete random variable $X$, the PMF is defined as:
- $p(x) = P(X = x)$
- A function $p(x)$ is a valid PMF if:
- Non-negativity: $p(x) \geq 0 \forall x$
- Total probability equals $1 \sum_{x} p(x) = 1$
- Probability at a point is meaningful
- $P(X = x) = p(x)$

# Probability Mass Functions (PMF)

- Probability Using PMF
- $P(a \leq X \leq b) = \sum_{x=a}^{b} p(x)$
- Examples
- Bernoulli Distribution
- $p(x) = \begin{cases} p, &amp; x = 1 \\ 1-p, &amp; x = 0 \end{cases}$
- Models success/failure
- Mean = $p$
- Variance = $p(1-p)$
- $P(X=x) = p^x(1-p)^{1-x}, x \in \{0,1\}$

# Other Examples

- Binomial Distribution
- Geometric Distribution
- Discrete Uniform Distribution

# Exponential Families

- Idea: If $P$ has some special Form =&gt; Some of the inference come for free.
- Exponential families are a class of distributions whose probability density function (PDF) can be molded into the following $P(y; \eta) = b(y) \exp(\eta^T * T(y) - a(\eta))$

- $\eta$ – Natural parameter (can be a scalar or a vector quantity)
- $y$ – Label for data
- $T(y)$ – Sufficient statistic (Here, it will be equal to $y$)
- $a(\eta)$ – Log-partition function (It should be purely a function of eta)
- $b(y)$ – It should be purely a function of $y$

# Examples of Exponential Family: Bernoulli Distribution

$$
\begin{array}{l}
P(y; \phi) = \phi^{y} * (1 - \phi)^{(1 - y)} \\
= \exp\left(\log\left(\phi^{y} * (1 - \phi)^{(1 - y)}\right)\right) \\
= \exp\left(y * \log(\phi) + (1 - y) * \log(1 - \phi)\right) \\
= \exp\left(y * \log(\phi / 1 - \phi)\right) + \log(1 - \phi) - Eq2
\end{array}
$$

By Comparing Eq2 with the following Equation

$$
P(y; \eta) = b(y) \exp(\eta^{T} * T(y) - a(\eta))
$$

$$
\eta = \log(\Phi / 1 - \Phi) =&gt; \Phi = 1 / (1 + e^{(- \eta)}) \quad , \quad T(y) = y, \quad \text{and} \quad a(\eta) = -\log(1 - \Phi)
$$

Note: As mentioned above the value of phi (which is the same as the activation or sigmoid function for Logistic regression) is not a coincidence. And it will be proved later in the article how Logistic regression model can be derived from the Bernoulli distribution.

# Why do we care about this form?

- Inference is easy
- Expectation E[y;η] = ∂a(η) / ∂η
- Variance Var[y;η] = ∂2a(η) / ∂2η
- Learning is well defined for the form.
- Maximum Likelihood Estimation (MLE) w.r.t. η is concave and provide global minimum.

# Exponential Families

The exponential family of distributions forms a broad and essential class of probability distributions widely used in statistical modeling and machine learning. These distributions share a canonical form, simplifying inference, parameter estimation, and theoretical analysis. Key benefits include:

- Unified Framework: Many common distributions like Gaussian, Bernoulli, and Multinomial can be expressed in this form.
- Efficient Estimation: Maximum likelihood estimation (MLE) and Bayesian inference are straightforward for this family.
- Sufficient Statistics: They encapsulate all necessary information about the data in compact forms (e.g., mean, variance).

Applications: Regression, and Learning algorithms.

# Generalization in GLMs

"Generalization" in Generalized Linear Models (GLMs) refers to the extension of simple linear models to handle a broader range of data characteristics

Generalization of Response Variable Distribution:

- Linear models assume the response variable $y$ follows a normal distribution.
- GLMs generalize this by allowing the response variable to belong to the exponential family of distributions, which includes:
- Normal distribution for continuous data.
- Binomial distribution for binary outcomes.
- Poisson distribution for counting data.

# Generalized Linear Models

- Generalized Linear Models (GLMs) are a class of regression models that can be used to model a wide range of relationships between a response variable and one or more predictor variables. Unlike traditional linear regression models, which assume a linear relationship between the response and predictor variables, GLMs allow for more flexible, non-linear relationships by using a different underlying statistical distribution.

# Generalization in GLMs...

- Generalization of the Relationship Between Predictors and Response:
- In linear models, the mean response $\mu$ is modeled directly as a linear function of predictors ($\mu = w^T x$).
- GLMs introduce a link function $g(\mu)$ to connect the predictors $w^T x$ to the mean of the response: $g(\mu) = w^T x$.
- This allows for nonlinear relationships between predictors and the response.

# Generalization in GLMs...

- Flexible extension of linear regression models, designed to handle a variety of response distributions and nonlinear relationships. They consist of three key components:
- Random Component: Specifies the distribution of the response variable $y$, which belongs to the exponential family (e.g., normal, binomial, Poisson).
- Systematic Component: A linear predictor $\eta = w^T x$, where $w$ is the weight vector and $x$ is the input vector.
- Link Function: Relates the mean of the response variable $\mu$ to the linear predictor via an invertible function $g: \mu = g^{-1}(\eta)$

# Features of GLMs

- **Flexibility**: GLMs can model a wide range of relationships between the response and predictor variables, including linear, logistic, Poisson, and exponential relationships.
- **Model interpretability**: GLMs provide a clear interpretation of the relationship between the response and predictor variables, as well as the effect of each predictor on the response.
- **Robustness**: GLMs can be robust to outliers and other anomalies in the data, as they allow for non-normal distributions of the response variable.
- **Scalability**: GLMs can be used for large datasets and complex models, as they have efficient algorithms for model fitting and prediction.
- **Ease of use**: GLMs are relatively easy to understand and use, especially compared to more complex models such as neural networks or decision trees.
- **Hypothesis testing**: GLMs allow for hypothesis testing and statistical inference, which can be useful in many applications where it's important to understand the significance of relationships between variables.
- **Regularization**: GLMs can be regularized to reduce overfitting and improve model performance, using techniques such as Lasso, Ridge, or Elastic Net regression.

# Generalized Linear Models

Generalized Linear Models (GLMs) are a flexible extension of ordinary linear regression, unifying models like linear, logistic, and Poisson regression by allowing the response variable to follow different distributions (not just normal) and using a link function to connect the linear predictor to the mean response.

They work for various data types (binary, counts, continuous) by specifying the distribution (Binomial, Poisson, Gamma, etc.) and the link function (logit, log, identity) that transforms the linear part to the expected outcome.

# Why Use GLMs?

☐ Flexibility: Handles non-normal data, such as yes/no answers (logistic) or event counts (Poisson).
☐ Unified Framework: Unifies different regression types under one structure, simplifying modeling.
☐ Interpretability: Maintains clear interpretation of predictor effects via the link function.

# Linear Models Vs Generalized Linear Models

## Linear Model: Guass 1809

- $y_i$'s are independent.
- $y$ follows normal distribution.
- $\mu_i = x_i^T \beta = x_0 \beta_0 + x_1 \beta_1 + \ldots$
- Least square or maximum likelihood estimation is used for optimization. (Both methods give us same result.)

## Generalized Linear Model: Nelder and Wedderburn in 1972

- $y_i$'s are independent.
- $y$ follows exponential family distribution.
- $g(\mu_i) = x_i^T \beta$: Any function may be logit or inverse or any other form.
- Only Maximum Likely Hood Estimation (MLE) is used.

# General Form of the Exponential Family

Rewriting $p(x)$ in a canonical form:

- $p(x) = h(x)\exp\left(\eta^T T(x) - A(\eta)\right)$
- $h(x)$: base measure,
- $\eta$: natural parameter (possibly a vector),
- $T(x)$: sufficient statistics,
- $A(\eta)$: log-partition function, $A(\eta) = \log Z(\eta)$.

- The term **log-partition function**, denoted $A(\eta)$ in the general exponential family formulation, derives its name because it is the logarithm of the **partition function** $Z(\eta)$, which normalizes the probability distribution.

# Probit Regression

# Generalized Linear Models for Binary Classification

In binary classification, we aim to model the probability of an outcome $y \in \{0,1\}$ given an input feature vector $x_i$. A common approach is to use generalized linear models (GLMs), which assume that the probability function can be written as:

$p(y = 1 \mid x_i, w) = g^{-1}(w^T x_i)$

$\triangle g^{-1}(\cdot)$ is a function that maps real numbers $[-\infty, \infty]$ to a probability range $[0, 1]$.

$\triangle w^T x_i$ represents a linear combination of the input features.

The function $g^{-1}(\cdot)$ is often referred to as the mean function or link function.

# Probit Regression vs. Logistic Regression

- In logistic regression, we use the sigmoid function (logistic function):
- $p(y = 1 \mid x_i, w) = \sigma(w^T x_i) = \frac{1}{1 + e^{-w^T x_i}}$
- The sigmoid function ensures the probability is always between 0 and 1.

- In probit regression, we replace the sigmoid function with the cumulative distribution function (CDF) of the standard normal distribution $\Phi(\eta)$:
- $p(y = 1 \mid x_i, w) = \Phi(w^T x_i)$
- where $\Phi(\eta)$ is defined as:
- $\Phi(\eta) = \int_{-\infty}^{\eta} \frac{1}{\sqrt{2\pi}} e^{-t^2 / 2} dt$

- This function represents the probability that a standard normal variable is less than $\eta$.
- Instead of using the logistic function, we model the probability using the normal distribution's cumulative probability.
- If $w^T x_i$ is very large, $\Phi(w^T x_i) \approx 1$: if $w^T x_i$ is very small, $\Phi(w^T x_i) \approx 0$.

# Probit Regression

$\diamond$ Probit regression is a statistical model used for binary classification. Unlike logistic regression, which assumes a logistic (sigmoid) function, probit regression models the probability of an event occurring using the cumulative distribution function (CDF) of the standard normal distribution:

- $p(y = 1 | x_i, w) = \Phi(w^T x_i)$
- $\Phi(\eta)$ is the standard normal CDF, mapping the real line $[-\infty, \infty]$ to the probability range $[0, 1]$.
- Why Probit Instead of Logistic Regression?
- Both models are used for binary classification.
- Logistic regression assumes logistic (sigmoid) transformation, while probit regression assumes a normal cumulative distribution function (CDF).
- If the latent variable follows a normal distribution, probit regression is preferred.

# Probit Regression..

Probit regression, $\Phi(\mu_i)$ is used to model the probability of the outcome

- $\phi(\mu_i)$ - Standard Normal PDF (Probability Density Function):
- Defined as: $\phi(\mu_i) = \frac{1}{\sqrt{2\pi}} e^{-\frac{\mu_i^2}{2}}$
- $\Phi(\mu_i)$ - Standard Normal CDF (Cumulative Distribution Function):
- Represents the probability that a standard normal variable is less than or equal to $\mu_i$.
- Defined as the integral of the PDF: $\Phi(\mu_i) = \int_{-\infty}^{\mu_i} \phi(t) dt$

|  Property | Logistic Function $\sigma(\eta)$ | Probit Function $\Phi(\eta)$  |
| --- | --- | --- |
|  Definition | $\sum_{-\infty}^{\infty} \phi(t) dt$ | $\int_{-\infty}^{\infty} \phi(t) dt$  |
|  Derivative (Slope) | $\sigma(\eta)(1 - \sigma(\eta))$ | $\phi(\eta)$  |
|  Range | (0,1) | (0,1)  |
|  Interpretation | Based on odds and logit transform | Based on normal probability  |
|  Extreme Cases | $\sigma(\eta) \approx 0$ for $\eta \to -\infty$, $\sigma(\eta) \approx 1$ for $\eta \to \infty$ | $\Phi(\eta) \approx 0$ for $\eta \to -\infty$, $\Phi(\eta) \approx 1$ for $\eta \to \infty$  |

# Multi-Task Learning (MTL)

# Introduction

- In many real-world scenarios, we need to train multiple related models simultaneously.
- Instead of training separate models for each task, Multi-Task Learning (MTL) leverages shared information among tasks to improve overall performance.
- This approach assumes that different tasks share some common structure in their input-output relationships.
- By jointly learning the tasks, the model generalizes better, especially when some tasks have limited training data.

# Examples of Multi-Task Learning

- Speech Recognition: Learning phoneme recognition across multiple languages.¹
- Medical Diagnosis: Predicting multiple related diseases based on patient history.²
- Computer Vision: Object detection and segmentation trained together.³
- Natural Language Processing (NLP): Sentiment analysis and emotion detection trained together.⁴

# Multi-Task Learning

- Instead of training separate models for each task, MTL learns a shared representation across all tasks.
- Given $T$ related tasks, where each task $t$ has:
- Dataset: $D_t = \{(x_i, y_i)\}_{i=1}^{N_t}$
- Model: $f_t(x)$
- Loss Function: $L_t(f_t(x), y)$
- MTL minimizes a combined objective $L = \sum_{t=1}^{T} L_t(f_t(x), y)$
- $L_t$ is the loss for task $t$.
- The key assumption is that some model parameters are shared across tasks to improve generalization
- Caruana, Rich. "Multitask learning." *Machine learning* 28 (1997): 41-75.

# Approaches to Multi-Task Learning

## Parameter Sharing

- Each task has its own model, but regularization forces the models to remain similar.
- Example: Using $\ell_2$ regularization to encourage parameters to be close

$$
L = \sum_{t=1}^{T} L_t(f_t(x), y) + \lambda \sum_{t \ne t'} \|W_t - W_{t'}\|^2
$$

|  $W_t$ = parameter vector for task $t$  |
| --- |
|  $W_{t'}$ = parameter vector for task $t'$  |
|  $\|\cdot\|^2$ = squared $t_s$ (Euclidean) norm  |
|  $\lambda$ = regularization strength  |

- Sun, Shiliang, Honglei Shi, and Yuanbin Wu. "A survey of multi-source domain adaptation." *Information Fusion* 24 (2015): 84-92.
- Zhang, Y. and Yang, Q., 2021. A survey on multi-task learning. *IEEE transactions on knowledge and data engineering*, 34(12), pp.5586-5609.

# Approaches to Multi-Task Learning...

- Bayesian Multi-Task Learning (Hierarchical Models): Statistical Model
- Assumption: Task-specific models are drawn from a shared prior.
- Use Bayesian techniques to estimate a shared prior distribution over task parameters.
- Example: $W_t \sim \mathcal{N}(W_{\text{shared}}, \Sigma)$
- $W_{\text{shared}}$ is the mean of all tasks.
- $\Sigma$ models task variability.
- Example Suppose:
- Task A has 1,000 samples
- Task B has 20 samples
- Without penalty:
- Task B overfits
- With similarity penalty:
- Task B's parameters move closer to Task A's
- Task B learns a more stable model

# Use of Hierarchical Bayesian Models

- Some groups (or tasks) may have a lot of data, allowing us to estimate parameters reliably.
- Other groups may have very little data, making parameter estimation difficult.
- A hierarchical Bayesian approach shares information across groups, so groups with less data can "borrow strength" from groups with more data.

# Example Formulation: Hierarchical Bayesian Models

Given a dataset where:
- $y_{ij}$ is the response (output) for the $i$-th item in group $j$.
- $x_{ij}$ is the feature vector associated with $y_{ij}$.
- $j$ represents different groups (tasks) for example different schools and i might index students within school.

Our goal is to estimate the probability distribution $p(y_{j}|x_{j})$ for all $j$.

# Example Formulation: Hierarchical Bayesian Models..

$\Leftrightarrow$  Generalized Linear Model (GLM): The expected value of  $y_{ij}$  is given by  $E[y_{ij}|x_{ij}] = g(x_{ij}^T\beta_j)$  where  $g(\cdot)$  is a link function (e.g., logistic function for classification or identity function for regression).

$\Leftrightarrow$  Group-Specific Parameters: Each group  $j$  has a separate parameter  $\beta_{j}$ , but they are not completely independent.

Hierarchical Prior on Parameters:  $\beta_{j} \sim N(\beta_{*}, \sigma_{j}^{2}I)$  where  $\beta_{*}$  is a global mean parameter shared across groups.

Global Prior:  $\beta_{*} \sim N(\mu, \sigma_{*}^{2}I)$

$\sigma_{j}^{2}$  controls how much group  $j$  depends on the common mean  $\beta_{*}$ .
$\sigma_{*}^{2}$  controls the overall variability in the population.

# Example Formulation: Hierarchical Bayesian Models..

- If we have a lot of data for group $j$, $\beta_j$ is learned mostly from that data.
- If we have little data for group $j$, $\beta_j$ is pulled toward $\beta_*$, which is estimated using all groups.
- This approach **adapts** to the amount of data available in each group, ensuring **better generalization** than separate models.

# Applications

- **Education Modeling:**
- Groups: Schools
- Features: Student demographics, teacher quality, etc.
- Output: Average test scores per school
- Advantage: Small schools benefit from data from larger schools.

- **Customer Purchase Prediction (Discrete Choice Modeling):**
- Groups: Individuals
- Features: Browsing history, age, location, etc.
- Output: Purchased product category
- Advantage: New customers benefit from similar existing customers.

- **Healthcare Prediction:**
- Groups: Hospitals
- Features: Patient demographics, symptoms, etc.
- Output: Disease diagnosis probability
- Advantage: Small hospitals leverage data from larger hospitals.
